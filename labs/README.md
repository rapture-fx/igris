# SCHLEP LABS — ARCHIVED R&D MODULES

This directory preserves cognitive, scaling, RL, and research work. **Not part of the production build.** Move any active research here before opening PRs.

## Directory Structure

- **research/** - Experimental Rust modules (cognitive, RL, predictive, autonomous, SLO enforcer)
- **cognitive/** - Cognitive reasoning experiments and JSON outputs
- **scaling/** - Auto-scaling research
- **validation/** - Shadow evaluation frameworks
- **_archive/** - Older archived code

## Purpose

These modules represent advanced features from Phases 10-13 that are:
- Experimental and not production-ready
- Requiring further research and validation
- May be integrated into core product in future phases
- Serving as R&D prototypes for innovative approaches

## Integration Path

Before promoting any labs module to core:
1. Ensure clear documentation and test coverage
2. Validate through benchmarks showing measurable improvements
3. Align with product roadmap
4. Get approval from engineering leads
