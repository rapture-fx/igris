## 🚦 **Deployment Guide**

### **One-Command Production Deployment**
```bash
# Clone repository
git clone https://github.com/yourorg/pollarbase.git
cd pollarbase/packages/backend

# Deploy with optimized architecture
chmod +x scripts/deploy_phase3.sh
./scripts/deploy_phase3.sh

# Access application
# Core API: http://localhost:8000
# ML Service: http://localhost:8001  
# Frontend: http://localhost:3000
# Monitoring: http://localhost:3000 (Grafana)
```

### **Environment Configuration**
```bash
# Production environment variables
DATABASE_URL=postgresql+asyncpg://pollarbase:password@postgres:5432/pollarbase
REDIS_URL=redis://redis:6379/0
ML_SERVICE_URL=http://pollarbase-ml:8001
USE_REMOTE_ML_SERVICE=true
SECRET_KEY=your-production-secret
```

### **Scaling Configuration**
```yaml
# Horizontal scaling for Core API
docker-compose -f docker-compose.ml.yml up --scale pollarbase-api=3

# Resource allocation for ML service
deploy:
  resources:
    limits:
      memory: 4G
      cpus: '2.0'
```
