# Igris Inertial

Deterministic AI execution for machines and AI agents.

## Installation

```bash
curl -sSL https://raw.githubusercontent.com/Igris-inertial/Igris/main/install.sh | sh
```

## Structure

- `/runtime` - Edge AI runtime (Rust, 16MB binary)
- `/overture` - Fleet control plane (Go) - Horizon/Infinite tiers only
