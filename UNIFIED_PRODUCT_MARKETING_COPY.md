### FAQ
**New (Unified Q&A)**:
```
Frequently Asked Questions

Q: Do I need cloud providers or can I run fully offline?
A: Both! Run 100% offline on edge devices, or add cloud providers for intelligent routing when online. The platform handles the handoff automatically.

Q: What happens if I lose internet connection?
A: Your edge devices continue running locally with zero interruption. When connectivity returns, cloud routing resumes automatically.

Q: Do I pay separately for cloud and edge?
A: No. One subscription includes both edge devices AND cloud request quotas. Simple, unified billing.

Q: Can I use my own AI models?
A: Yes. Run any GGUF model locally on edge devices. Add any OpenAI-compatible provider for cloud routing.

Q: What counts as a "device"?
A: Any instance running the Igris runtime. Servers, robots, edge devices, IoT gateways—each instance is one device.

Q: What counts as a "cloud request"?
A: Any request routed through the cloud gateway to external AI providers (OpenAI, Anthropic, etc). Local edge execution doesn't count.

Q: Can I start free and upgrade later?
A: Yes. The Seed tier is free forever (1 device + 50k cloud requests). Upgrade anytime as you scale.

Q: Is my data secure?
A: Edge execution keeps data on your devices. Cloud routing uses encrypted connections. Cryptographic proof system verifies every decision.

Q: Can I deploy on-premise?
A: Yes, starting with The Infinite tier. Full platform deployment on your infrastructure.

Q: Do you support [specific AI provider]?
A: We support 10+ providers out of the box. Custom providers available in paid tiers.
```
