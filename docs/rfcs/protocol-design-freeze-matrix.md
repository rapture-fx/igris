# Igris protocol design-freeze matrix

Status: **Candidate for senior approval**

Classification:

- **MUST FREEZE BEFORE V2**: approve the invariant and exact vectors before any
  Evidence v2 or ActionContract v2 producer emits externally visible bytes.
- **SAFE TO DEFER**: keep out of the minimum format; later addition requires an
  explicit compatible extension or new schema.
- **SHOULD NOT ENTER THE PROTOCOL**: keep as binding, product, transport, or
  application behavior.

“Signed-byte impact” states whether a future choice changes signed bytes. A
verifier-policy-only decision may change trust or acceptance results without
changing mathematical signature validity. Existing schema `1` behavior is
always preserved even where the v2 recommendation differs.

## Candidate freeze result

The matrix permits freezing the compatibility and claim-boundary invariants.
It does not permit emitting v2 bytes. Rows marked **YES** under “Freeze now”
that still name an exact open choice must be resolved in
[`protocol-open-decisions.md`](protocol-open-decisions.md) and represented by
golden vectors before implementation.
