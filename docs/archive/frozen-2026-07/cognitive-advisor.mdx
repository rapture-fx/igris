# Routing Advisor (Technical Preview)

The Routing Advisor is an advanced operator surface for reviewing suggested path-selection changes.

It belongs under the **Execute** stage of Igris, not the top-level product story. The primary value is still governed execution with visible decisions, signed records, and verification-ready receipts.

See [Proof Status](/docs/proof-status) before treating this page as a production commitment.

---

## What It Does

In configurations that expose advisor functionality, the system can review recent execution outcomes and surface suggestions such as:

- shifting between configured execution paths
- adjusting provider preferences
- changing how aggressively fallbacks are used

Those suggestions should be treated as operator proposals, not automatic truth.

---

## Recommended Operating Model

Use advisor-style workflows conservatively:

1. review the proposal
2. compare it with recent execution events and receipts
3. apply changes deliberately
4. watch the next runs before promoting the change further

Automatic application should only be used when you understand the underlying risk and have rollback procedures in place.

---

## What This Page Does Not Claim

This page does not claim:

- guaranteed improvements
- automatic safe optimization for every workload
- proof-backed production auto-tuning across all deployments

Treat any advisor-driven workflow as advanced and configuration-dependent.
