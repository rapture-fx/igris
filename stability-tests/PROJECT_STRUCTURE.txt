TEST EXECUTION OPTIONS
======================

🚀 Quick Smoke Test (2 min)
   python3 load_test_basic_requests.py --url http://localhost:8081 --requests 100 --concurrency 10

⚡ Critical Tests Only (10 min)
   - FFI Boundary Stress
   - Streaming Reliability
   - Load Test
   - Format Validation

🎯 Full Test Suite (25 min)
   ./run_all_tests.sh
   (All 9 tests + comprehensive report)


SUCCESS CRITERIA
================

🔴 CRITICAL (Must Pass):
   - 5xx Error Rate: 0%
   - API Availability: ≥99.9%
   - FFI Panics: 0
   - Stream Completion: ≥99%
   - Broken Pipes: 0
   - Server Crashes: 0

🟡 WARNING (Should Pass):
   - P95 Latency: <2000ms
   - Memory Growth: <10%


COST SAFETY
===========

💰 Benchmark Mode (Default):
   - Zero API costs
   - Realistic latency simulation
   - Safe for aggressive testing
   - Reproducible results

⚠️  Real Mode (Sparingly):
   - Incurs real API costs
   - Use only for final validation
   - Set MAX_MONTHLY_COST_USD=5


MONITORING SETUP

ROLLBACK PROCEDURES
===================

# Automatic
./scripts/rollback_automation.sh

# Manual (Kubernetes)
kubectl rollout undo deployment/schlep-engine-api

# Manual (Docker)
docker-compose down && docker-compose up -d
