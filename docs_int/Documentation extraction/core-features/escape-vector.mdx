# EscapeVector Mode

## Overview

**EscapeVector Mode** is Igris Inertial's zero-downtime failover system that uses Thompson Sampling Bayesian optimization to maintain intelligent AI routing even when the control plane is completely unavailable.

While competitors revert to round-robin during outages, EscapeVector continues running the **exact same Thompson Sampling algorithm** that powers normal operation, ensuring optimal provider selection during failures.

## Key Features

### Thompson Sampling Fallback (< 400 KB binary)

- **Automatic Trigger**: Switches to local fallback after 3 consecutive timeouts (> 500ms) or request failures
- **Bayesian Intelligence**: Maintains alpha/beta parameters per provider for optimal selection
- **Exploration/Exploitation**: Continues optimal exploration using Beta distribution sampling even offline
- **Circuit Breakers**: Per-provider health tracking with atomic operations
- **Speculative Execution**: Optional parallel racing with Bayesian winner selection

### Inertial Quorum (72-Hour Cache)

- **Encrypted Persistence**: AES-256-GCM + HMAC signature for secure state storage
- **Tamper Protection**: Clock rollback detection to prevent manipulation
- **Automatic Sync**: Background refresh on every successful request
- **Graceful Expiration**: Forces Gold Code Override after 72-hour TTL

### Gold Code Override

- **Environment Variable**: `BYOK_BYPASS_CONTROL_PLANE=true`
- **Bypass Forever**: Skips control plane permanently for air-gapped deployments
- **Thompson or Round-Robin**: Configurable fallback strategy

## Usage

### Basic Usage (Automatic)

EscapeVector Mode activates automatically when the control plane becomes unavailable:

```go
import "github.com/igris-inertial/igris-inertial/internal/sdk/go/igris"

client := igris.NewClient(&igris.Config{
    BaseURL: "http://localhost:8081",
    APIKey:  "your-api-key",
})

// EscapeVector Mode activates automatically on control plane failure
response, err := client.Infer(ctx, &igris.InferRequest{
    Model: "gpt-4",
    Messages: []igris.Message{
        {Role: "user", Content: "Hello!"},
    },
})
```

### Gold Code Override

For air-gapped or permanently offline deployments:

```bash
# Force bypass control plane forever
export BYOK_BYPASS_CONTROL_PLANE=true

# Custom cache directory
export IGRIS_CACHE_DIR="/custom/path"
```

```go
// Client automatically uses Thompson Sampling fallback

```

## Security

### Encryption

- **Algorithm**: AES-256-GCM with authenticated encryption
- **Key Derivation**: SHA-256 hash of API key
- **Integrity**: HMAC-SHA256 signature verification

### Tamper Protection

- Clock rollback detection (5-minute tolerance)
- HMAC verification on every cache load
- Automatic fallback to Gold Code Override on tampering

### Cache Location

- **Default**: `~/.config/igris/bayesian_state.enc`
- **Permissions**: 0600 (owner read/write only)
- **Format**: JSON-encrypted blob

## Thompson Sampling Algorithm

### Selection Process

```go
// For each arm, sample from Beta(α, β)
sample_i = Beta(arm_i.Alpha, arm_i.Beta)

// Select arm with highest sample
selected_arm = argmax(sample_i)
```

### Update on Success

```go
arm.Alpha += 1.0
arm.TotalSuccesses++
arm.AvgLatencyScore = EMA(arm.AvgLatencyScore, normalizedLatency)
```

### Update on Failure

```go
arm.Beta += 1.0
arm.TotalFailures++
```

### Composite Reward

```
reward = α·latency_score + β·cost_efficiency + γ·success_rate
```

Where:
- `latency_score = 1 - (latency / max_latency)` ∈ [0, 1]
- `cost_efficiency = 1 - (cost / max_cost)` ∈ [0, 1]
- `success_rate = 1 if success else 0` ∈ {0, 1}

## FAQ

### When does EscapeVector Mode activate?

After 3 consecutive requests with latency > 500ms OR request failures.

### How long does the cache persist?

72 hours. After expiration, falls back to Gold Code Override (default providers with α=1, β=1).

### Can I force bypass the control plane?

Yes, set `BYOK_BYPASS_CONTROL_PLANE=true` environment variable.

### What happens if my clock is tampered?

Cache loading fails and forces Gold Code Override for security.

### Does exploration continue during outages?

Yes, with ε-greedy exploration rate (default 10%).

### How does this compare to production Thompson Sampling?

Identical algorithm. Same Beta distribution sampling, same composite rewards, same exploration strategy.
