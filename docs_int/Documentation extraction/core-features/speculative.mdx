# Speculative Execution

## Overview

**Speculative Execution** is Igris Inertial's parallel provider racing system that simultaneously queries multiple AI providers and intelligently selects the best response using Bayesian winner selection. Unlike naive racing that simply returns the fastest response, Speculative Execution considers quality, cost, and performance history to make optimal decisions.

This feature is integrated into both normal operation and [EscapeVector Mode](/docs/core-features/escape-vector) for maximum resilience.

## Key Features

### Bayesian Winner Selection

- **Multi-Factor Scoring**: Evaluates latency, cost, and quality
- **Thompson Sampling Integration**: Leverages existing α/β parameters
- **Composite Rewards**: Same reward function as primary routing
- **Learning from Races**: Updates provider parameters based on race outcomes

### Intelligent Racing

- **Selective Activation**: Only races when providers are closely matched
- **Resource Awareness**: Respects rate limits and circuit breaker states
- **Cost Optimization**: Cancels expensive providers when fast alternative completes
- **Quality First**: Prioritizes response quality over pure speed

### Configurable Strategy

- **Race Count**: Control how many providers to race (default: 2-3)
- **Timeout Management**: Independent timeouts per provider
- **Cost Limits**: Skip expensive providers in races
- **Quality Thresholds**: Minimum quality scores for race participants

## How It Works

### 1. Race Decision

The system decides whether to race based on:

```go
func shouldRace(providers []Provider) bool {
    // Check if top providers are closely matched
    if len(providers) < 2 {
        return false
    }

    top := providers[0]
    second := providers[1]

    // Race if confidence difference < 15%
    confidenceDiff := abs(top.Confidence - second.Confidence)
    return confidenceDiff < 0.15
}
```

### 2. Parallel Execution

```go
func speculativeInfer(ctx context.Context, req *InferRequest) (*InferResponse, error) {
    // Select top N providers for racing
    raceProviders := selectRaceProviders(req, 3)

    // Launch parallel requests
    results := make(chan *RaceResult, len(raceProviders))
    ctx, cancel := context.WithTimeout(ctx, 30*time.Second)
    defer cancel()

    for _, provider := range raceProviders {
        go func(p Provider) {
            start := time.Now()
            resp, err := p.Infer(ctx, req)

            results <- &RaceResult{
                Provider: p,
                Response: resp,
                Error:    err,
                Latency:  time.Since(start),
            }
        }(provider)
    }

    // Collect and score results
    return selectWinner(ctx, results, raceProviders)
}
```

### 3. Winner Selection

```go
func selectWinner(results []*RaceResult) *RaceResult {
    var best *RaceResult
    var bestScore float64

    for _, result := range results {
        if result.Error != nil {
            continue
        }

        // Calculate composite score
        score := calculateCompositeScore(result)

        if score > bestScore {
            best = result
            bestScore = score
        }
    }

    return best
}

func calculateCompositeScore(result *RaceResult) float64 {
    // Same scoring as Thompson Sampling
    latencyScore := 1.0 - (result.Latency / maxLatency)
    costScore := 1.0 - (result.Cost / maxCost)
    qualityScore := result.Quality // From response validation

    return weightLatency*latencyScore +
           weightCost*costScore +
           weightQuality*qualityScore
}
```

## Configuration

### Enable Speculative Execution

```go
client := igris.NewClient(&igris.Config{
    APIKey: "your-api-key",
    SpeculativeExecution: true,
    RaceCount: 3, // Race top 3 providers
    RaceTimeout: 30 * time.Second,
    RaceCostLimit: 0.05, // Max $0.05 per race
})
```

### Environment Variables

```bash
# Enable speculative execution
IGRIS_SPECULATIVE_ENABLED=true

# Number of providers to race
IGRIS_RACE_COUNT=3

# Maximum cost per race (USD)

# Minimum confidence difference to trigger race
IGRIS_RACE_CONFIDENCE_THRESHOLD=0.15

```

### Per-Request Control

```go
response, err := client.Infer(ctx, &igris.InferRequest{
    Model: "gpt-4",
    Messages: messages,
    Options: &InferOptions{
        ForceRace: true, // Always race for this request
        RaceProviders: []string{"openai", "anthropic"}, // Specific providers
        MaxRaceCost: 0.10, // Custom cost limit
    },
})
```

## Limitations

### Resource Overhead

- Increases API call volume proportional to race count
- Higher memory usage during parallel execution
- Network bandwidth multiplied by race count

### Provider Rate Limits

- Each raced provider counts toward rate limits
- May exhaust limits faster during high traffic
- Circuit breakers still apply per provider

### Cost Implications

- Direct cost increase (1.3-2.0x typical)
- Must monitor spend carefully
- Cost controls essential for production

## FAQ

### Does speculative execution always run?

No, it only activates when:
1. Multiple providers have similar confidence scores
2. Cost limits not exceeded
3. Resources available (rate limits, circuit breakers)

### What happens to losing responses?

They're discarded, but the outcome (latency, cost) is recorded and used to update Thompson Sampling parameters.

### Can I race specific providers?

Yes, use the `RaceProviders` option in the request:

```go
response, err := client.Infer(ctx, &igris.InferRequest{
    Model: "gpt-4",
    Options: &InferOptions{
        RaceProviders: []string{"openai", "anthropic"},
    },
})
```

### How does this work in EscapeVector Mode?

Identically. The local Thompson Router races providers using cached parameters.

### What's the maximum race count?

Technically unlimited, but practically 2-4 providers. Beyond that, cost increases faster than performance improves.
