# API Reference

The API reference is served as a dedicated reference surface under `/docs/api-reference`. Use it
for the customer-facing endpoint contract, guide pages, and per-endpoint integration details.

## Start Here

- [Introduction](/docs/api-reference/introduction)
- [Authentication](/docs/api-reference/authentication)

## What The Reference Covers

- supported cloud inference routes
- hosted account, vault, billing, policy, and fleet endpoints
- local runtime endpoints that are part of the shipped product contract
- endpoint-level request shape, authentication model, status codes, and examples

Use the dedicated API reference pages when you are implementing or debugging a specific route. Use
the general docs when you are learning the product, deployment model, or operational workflows.
