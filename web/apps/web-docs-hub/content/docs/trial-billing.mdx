# Trial & Billing

---

## Free Trial

Every new account gets a 7-day trial on one tier.

### POST /v1/trial/start

```bash
curl -X POST https://overture.igrisinertial.com/v1/trial/start \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tier": "horizon"}'
```

Allowed values:

- `seed`
- `horizon`
- `infinite`

Successful responses are created with:

```json
{
  "status": "trial_started",
  "tier": "horizon",
  "days_left": 7,
  "ends_at": "2026-04-07T12:00:00Z",
  "message": "Your 7-day trial has started. No credit card required."
}
```

### GET /v1/trial/status

```bash
curl https://overture.igrisinertial.com/v1/trial/status \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Current response fields:

```json
{
  "trial_active": true,
  "trial_tier": "horizon",
  "current_tier": "horizon",
  "started_at": "2026-03-31T12:00:00Z",
  "ends_at": "2026-04-07T12:00:00Z",
  "days_left": 5
}
```

## API Key Management

The account API key endpoints are authenticated by either:

- a current `igris_...` API key in `Authorization: Bearer`
- a console session cookie when used from the web app

Do **not** document these endpoints as bearer session-token endpoints.

### GET /v1/account/api-key

```bash
curl https://overture.igrisinertial.com/v1/account/api-key \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response:

```json
{
  "has_key": true,
  "prefix": "igris_abc123",
  "created_at": "2026-03-01T12:00:00Z"
}
```

### POST /v1/account/api-key

```bash
curl -X POST https://overture.igrisinertial.com/v1/account/api-key \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response:

```json
{
  "api_key": "igris_abc123...",
  "prefix": "igris_abc123",
  "created_at": "2026-03-01T12:05:00Z"
}
```

### DELETE /v1/account/api-key

```bash
curl -X DELETE https://overture.igrisinertial.com/v1/account/api-key \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response:

```json
{
  "revoked": true
}
```
