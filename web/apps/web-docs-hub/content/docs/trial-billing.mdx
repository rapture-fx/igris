# Trial & Billing

Trial and billing controls are the account-side surfaces for choosing a tier, checking subscription status, and managing access to the commercial parts of Igris.

This page is about account lifecycle and access control. It should stay aligned with the main commercial story: verified execution, retention, operator access, and deployment scope.

---

## Free Trial

Every new account can start a 7-day trial on one tier.

### POST /v1/trial/start

```bash
curl -X POST https://overture.igrisinertial.com/v1/trial/start \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tier": "horizon"}'
```

Allowed values:

- `seed`
- `horizon`
- `infinite`

### GET /v1/trial/status

```bash
curl https://overture.igrisinertial.com/v1/trial/status \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Use this to answer:

- is the trial active
- which tier is active
- when the trial ends

## Subscription Status

### GET /api/subscription/status

```bash
curl https://overture.igrisinertial.com/api/subscription/status \
  -H "Authorization: Bearer YOUR_API_KEY"
```

This surface is most useful when operators need to understand:

- the active tier
- environment capacity in use versus limit
- whether an upgrade path is available

### GET /api/subscription/plans

```bash
curl https://overture.igrisinertial.com/api/subscription/plans \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Use this when the application or operator workflow needs plan metadata rather than marketing copy.

## API Key Management

These account endpoints let a tenant manage API-key access to the commercial surfaces.

### GET /v1/account/api-key
### POST /v1/account/api-key
### DELETE /v1/account/api-key

These routes are part of account access management, not of the execution model itself.

## Commercial Reading

When explaining billing or trial behavior, keep the message aligned with what the tiers actually differentiate:

- environment capacity
- retention
- operator visibility
- deployment flexibility

Avoid turning trial and billing into a feature-promise page for advanced preview surfaces.
