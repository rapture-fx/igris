# Docs Authoring

This docs site now uses the native Fumadocs layout and native Fumadocs MDX components.

## Native Components

- Code fences render through the native Fumadocs `CodeBlock` and `Pre` path.
- Tables render through the native Fumadocs MDX table wrapper.
- Tabs, steps, files, inline TOC, image zoom, and type tables are all wired through the shared Fumadocs MDX registry.

## Auto Type Table

`AutoTypeTable` is available in MDX through `fumadocs-typescript`.

<AutoTypeTable
  type="{ title: string; slug: string; description?: string; featured?: boolean }"
/>
