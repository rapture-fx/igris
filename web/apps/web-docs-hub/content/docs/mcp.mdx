# MCP

MCP is the agent-facing control surface in Igris. An agent connects to one endpoint
(`POST /v1/mcp`) and, scoped to its tenant, can do four things:

- discover the **registered actions** it is allowed to call
- call a registered action
- inspect the resulting runs and their proof state
- list the tenant's registered runtimes

It is a narrow, strict-schema JSON-RPC surface — not a general-purpose context or
resource store. The available tools are fixed (`list_actions`, `get_action`,
`call_action`, `list_runs`, `get_run`, `get_run_evidence`, `list_runtimes`), every
tool schema is closed (`additionalProperties: false`), and unknown fields are
rejected. The tenant always comes from the credential and cannot be overridden
through arguments.

## Transport Surface

- [`POST /v1/mcp`](/docs/mcp-server): JSON-RPC `tools/list` and `tools/call`

## How MCP Fits In

Use MCP to let an agent call your registered actions and read back what happened.
Use [durable tasks](/docs/durable-tasks) when long-running progress and recovery
matter. Use [receipts](/docs/execution-receipts) for audit evidence. Keeping those
three concerns separate is what keeps the system understandable at scale.
