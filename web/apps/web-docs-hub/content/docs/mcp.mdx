# MCP (Beta)

MCP is a **beta** agent-facing transport for registered Actions.

Endpoint:

```text
POST /v1/mcp
```

An agent connects with a tenant credential and can:

- discover registered Actions
- call a registered Action
- inspect resulting runs / evidence surfaces exposed by the tool set
- list registered runtimes for the tenant

The tool set is fixed and strict-schema (`additionalProperties: false`). Unknown fields are rejected. Tenant identity always comes from the credential.

## Current tool set

- `list_actions`
- `get_action`
- `call_action`
- `list_runs`
- `get_run`
- `get_run_evidence`
- `list_runtimes`

## How to use it in External Alpha

1. Complete the durable Action path first with `IgrisDurableClient` so your Action is registered, bound, and runnable.
2. Point your MCP-capable agent at `POST /v1/mcp` on your invitation endpoint.
3. Use tenant API key auth only — never paste raw keys into prompts or shared logs.

MCP is secondary to the durable SDK journey. Prefer [Your First Durable Action](/docs/first-durable-action) before MCP wiring.
