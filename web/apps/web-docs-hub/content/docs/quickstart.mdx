# Managed Python quickstart

This is the hosted-alpha product path:

**Action → Run → Proof**

REST is the canonical managed interface. The Python SDK shown here is a thin
convenience layer over it.

## Installation status

The Igris distribution is named `igris-sdk`, and the import is
`from igris import Igris`.

`igris-sdk` is not currently published on PyPI. Do not run
`pip install igris`; that name belongs to an unrelated project.

For a repository checkout or operator-supplied alpha kit:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install ./sdk/python
```

## Environment

Set the managed API URL and a tenant-scoped key in your shell or secret
manager. Do not commit either value.

```bash
export IGRIS_API_URL="https://your-managed-igris.example"
export IGRIS_API_KEY="igris_..."
```

## Setup once

An operator introduces an Action target and binds one exact Action contract to
it. This is setup, not work the coding agent repeats before every Run.

```python
from igris import Igris, wrap_tool

def deploy_staging(service: str, commit: str) -> dict:
    raise RuntimeError("contract declaration only; execution belongs to the target")

tool = wrap_tool(
    deploy_staging,
    action="deploy.staging",
    risk="critical",
    approval="never",
)

igris = Igris.from_env()

target = igris.create_action_target(
    name="deploy_staging_adapter",
    target_url="https://deploy.example.com/v1/deploy/staging",
    target_type="webhook",
    replay_class="non_retryable",
    approval_required=True,
    irreversible=True,
    target_metadata={
        "local_auth_header_name": "X-Igris-Adapter-Token",
        "local_auth_secret_env": "IGRIS_DEPLOY_STAGING_ADAPTER_TOKEN",
    },
)

igris.configure_action(
    tool,
    target_action_id=target.id,
    input_mapping={"service": "service", "commit": "commit"},
)
```

The target must use public HTTPS. Its hostname must also be present in the
Runtime's `allowed_http_domains`. Igris rejects unsafe addresses and redirects;
the tenant API key is never forwarded to the target.

The example function is used to declare the Action contract. Managed Igris does
not upload or invoke that local Python function.

## Ordinary Run

After setup, the coding agent only needs the Action name, inputs, and a stable
business idempotency key:

```python
import os

from igris import Igris

igris = Igris.from_env()

# After process restart, load the configured contract identity from your
# deployment configuration or pass the exact contract/tool to run().
igris.remember_contract(
    "deploy.staging",
    os.environ["IGRIS_DEPLOY_STAGING_CONTRACT_HASH"],
)

run = igris.run(
    "deploy.staging",
    input={"service": "api", "commit": "abc123"},
    idempotency_key="deploy:api:abc123",
)

status = run.wait(timeout=120)
proof = run.proof()

print(status.status)
print(proof.statuses)
```

`remember_contract()` is a local SDK cache; the managed service remains the
source of truth for the immutable contract binding and Run state.

## Idempotency

Use a key derived from the business operation, such as
`deploy:api:abc123`. Repeating the same request with the same key is safe at
the Igris submission boundary. Reusing the key with different inputs is a
conflict.

Idempotency does not make an external target exactly-once. The target should
also implement its own idempotency or lookup operation.

## Uncertain external effects

If the connection fails after dispatch, Igris may be unable to know whether
the target performed the operation. For an irreversible or non-retryable
Action, Igris stops automatic replay and surfaces
`reconciliation_required`.

Do not create a new idempotency key and try again blindly. First inspect the
external deployment provider, then use the authenticated
[Reconciliation](/docs/reconciliation) workflow.

## Proof

`run.proof()` returns the linked Run proof view. It can show what Igris
authorized, dispatched, observed, and cryptographically verified in its own
records. It does not cryptographically prove that an external deployment
produced the intended real-world result.
