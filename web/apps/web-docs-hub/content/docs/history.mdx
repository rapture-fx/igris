# History & Alerts

Igris records execution history, summary metrics, and alert state in the coordination layer.

---

## Execution Events

### GET /v1/history/events

Returns execution history events for the current tenant.

```bash
curl "https://overture.igrisinertial.com/v1/history/events?range=last_24h&limit=50" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Supported query parameters:

| Parameter | Description |
|---|---|
| `range` | Window selector such as `last_1h`, `last_24h`, `last_7d`, `1h`, `24h`, `7d` |
| `limit` | Max results, up to 2000 |
| `agent_id` | Filter by agent ID |
| `device_id` | Filter by runtime/device ID |

Response shape:

```json
[
  {
    "id": "lineage-01HXYZ",
    "execution_id": "exec-01HXYZ",
    "agent_id": "agent-abc",
    "device_id": "runtime-01",
    "timestamp": "2026-03-01T12:00:00Z",
    "duration_ms": 312,
    "event_type": "execution_completed",
    "severity": "info",
    "message": "Execution completed successfully"
  }
]
```

## Metrics

### GET /v1/history/metrics

Returns a summary plus throughput and recent metric events.

```bash
curl "https://overture.igrisinertial.com/v1/history/metrics?range=last_24h" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response shape:

```json
{
  "summary": {
    "executions_per_minute": 2.47,
    "avg_latency_ms": 287,
    "success_rate_percent": 99.7,
    "policy_violations": 3
  },
  "throughput": [
    { "time": "2026-03-01T11:00:00Z", "executions": 142 },
    { "time": "2026-03-01T12:00:00Z", "executions": 189 }
  ],
  "events": [
    {
      "id": "lineage-01HXYZ",
      "timestamp": "2026-03-01T12:00:00Z",
      "metric_name": "latency_ms",
      "metric_value": 287,
      "unit": "ms",
      "agent_id": "agent-abc",
      "device_id": "runtime-01",
      "provider": ""
    }
  ]
}
```

## Alerts

### GET /v1/history/alerts

Returns alert state for policy-violation executions.

```bash
curl "https://overture.igrisinertial.com/v1/history/alerts?range=last_24h&limit=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Supported query parameters:

| Parameter | Description |
|---|---|
| `range` | Window selector such as `last_24h` |
| `limit` | Max results, up to 1000 |

Response shape:

```json
[
  {
    "id": "lineage-01HABC",
    "execution_id": "exec-01HABC",
    "agent_id": "agent-abc",
    "device_id": "runtime-01",
    "timestamp": "2026-03-01T11:45:00Z",
    "severity": "error",
    "title": "Policy Violation",
    "message": "A policy violation was detected during execution of agent agent-abc",
    "status": "open"
  }
]
```

### Alert Actions

- `POST /v1/history/alerts/:id/acknowledge`
- `POST /v1/history/alerts/:id/resolve`
- `POST /v1/history/alerts/:id/escalate`

Each action operates on the alert row ID returned by `GET /v1/history/alerts`.
