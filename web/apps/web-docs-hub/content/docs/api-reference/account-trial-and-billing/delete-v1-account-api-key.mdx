# DELETE /v1/account/api-key

Revokes the current tenant API key. This endpoint belongs to the Account, Trial, and Billing group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `DELETE` |
| Path | `/v1/account/api-key` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie or igris_ API key |
| Surface | Cloud API |
| Stability | stable |
| Support | supported |
| Deployment | cloud |

## When To Use

Use this endpoint when you need revokes the current tenant api key. from the hosted API. It is part of the Account, Trial, and Billing surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Using the wrong credential type or forgetting to send the expected API key header.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Code Examples

### cURL

```bash
curl -X DELETE https://overture.igrisinertial.com/v1/account/api-key \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/account/api-key', {
  method: 'DELETE',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("DELETE", "https://overture.igrisinertial.com/v1/account/api-key", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::DELETE, "https://overture.igrisinertial.com/v1/account/api-key")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
