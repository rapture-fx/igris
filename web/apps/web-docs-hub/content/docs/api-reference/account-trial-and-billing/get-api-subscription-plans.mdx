# GET /api/subscription/plans

Lists available plans and checkout URLs. This endpoint belongs to the Account, Trial, and Billing group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/api/subscription/plans` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie or igris_ API key |
| Surface | Cloud API |
| Stability | stable |
| Support | supported |
| Deployment | cloud |

## When To Use

Use this endpoint when you need lists available plans and checkout urls. from the hosted API. It is part of the Account, Trial, and Billing surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Using the wrong credential type or forgetting to send the expected API key header.

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/api/subscription/plans \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/api/subscription/plans', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/api/subscription/plans", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/api/subscription/plans")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
