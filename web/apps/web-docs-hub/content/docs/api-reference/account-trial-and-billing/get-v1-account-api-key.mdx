# GET /v1/account/api-key

Returns metadata about the current tenant API key without exposing the secret itself. Use it to confirm whether a key exists, what prefix it has, and when it was last rotated.

## When To Use

Use this endpoint when you are auditing tenant access state, confirming whether an environment already has a key, or checking whether key rotation happened when expected.

## Integration Guidance

Safe to retry on transient 5xx or 429 responses. A missing key is a product state question, not a retry condition.

### Common Mistakes

- Expecting the raw API key to be returned again after creation.
- Using this route as if it creates or rotates credentials; it only reports metadata.

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/account/api-key \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/account/api-key', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/account/api-key", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/account/api-key")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
