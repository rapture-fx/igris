# GET /v1/tasks/:id

Returns the current state of one durable task, including runtime assignment and the latest checkpoint metadata when available. This is the status route you poll while a durable workflow is still in progress.

## When To Use

Use this endpoint after submission when you need to monitor progress, completion, failure, or recovery state for a specific task.

## Integration Guidance

Safe to retry on transient 5xx or 429 responses. Poll at a reasonable interval rather than continuously, especially for long-running tasks.

### Common Mistakes

- Polling too aggressively and turning task status checks into avoidable background load.
- Treating checkpoint metadata as if it will exist before the runtime has actually produced a checkpoint.

## Path Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | Task ID returned by POST /v1/tasks/submit. |

## Notes

- Status values: `pending`, `dispatched`, `checkpointed`, `completed`, `failed`, `recovering`.
- `last_step` and `checkpoint_digest` are only present once the runtime has pushed at least one checkpoint.

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/tasks/example-id \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/tasks/example-id', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/tasks/example-id", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)

payload, _ := io.ReadAll(resp.Body)

```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Success | Task record returned. |
| 400 | Bad request | Task ID is not a valid UUID. |
| 401 | Unauthorized | Session or API key auth failed. |
| 404 | Not found | No task with this ID exists for the authenticated tenant. |
