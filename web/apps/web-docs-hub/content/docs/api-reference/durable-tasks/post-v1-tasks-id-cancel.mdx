# POST /v1/tasks/:id/cancel

Requests cancellation for a durable task that is still cancellable. When the task is assigned to a runtime with a known endpoint, the coordinator also attempts to propagate the cancellation to the runtime.

## When To Use

Use this endpoint when the operation belongs to the Durable Tasks surface on the hosted API. It is intended to be the customer-facing contract for this capability.

## Integration Guidance

Do not retry blindly. A second cancellation request can return conflict once the task has moved into a terminal state.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Canceled | The task was moved to canceled state. |
| 400 | Bad request | Task ID is not a valid UUID. |
| 404 | Not found | No task with this ID exists for the authenticated tenant. |
| 409 | Transition rejected | The task is already terminal or otherwise cannot be canceled. |
