# GET /v1/actions/runs/:id

Inspects one action run in the authenticated tenant: lifecycle status, proof status, and a redacted input summary. Run inputs are never echoed back raw — inspection returns digests and safe summaries so evidence stays reviewable without exposing payloads.

## When To Use

Use this endpoint after submitting a run to follow it to completion, to confirm whether a retried request deduplicated onto an existing run, or to check proof status before treating the side effect as done.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.

## Path Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | Run id returned when the action run was accepted. |

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/actions/runs/example-id \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/actions/runs/example-id', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/actions/runs/example-id", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/actions/runs/example-id")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Run found | The run belongs to your tenant and its current state is returned. |
| 400 | Invalid run id | The run id was not a valid identifier. |
| 401 | Unauthorized | Credentials were missing, expired, or not accepted. |
| 404 | Run not found | No run with that id exists in your tenant. |
