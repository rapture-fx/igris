| Stability | stable |
| Support | supported |

## When To Use

Use this endpoint when you need gets a single behavior-tree definition. from the hosted API. It is part of the Behavior Trees surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/bt/definitions/example-id \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/bt/definitions/example-id', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();

```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/bt/definitions/example-id", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

