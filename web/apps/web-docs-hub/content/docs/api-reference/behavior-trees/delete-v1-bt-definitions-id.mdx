Deletes a behavior-tree definition. This endpoint belongs to the Behavior Trees group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `DELETE` |
| Path | `/v1/bt/definitions/:id` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie or igris_ API key |
| Surface | Cloud API |
| Stability | stable |
| Support | supported |
| Deployment | cloud |

## When To Use

Use this endpoint when you need deletes a behavior-tree definition. from the hosted API. It is part of the Behavior Trees surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("DELETE", "https://overture.igrisinertial.com/v1/bt/definitions/example-id", body)

	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

	log.Fatal(err)
```
