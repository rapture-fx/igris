Lists built-in behavior-tree templates. This endpoint belongs to the Behavior Trees group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/v1/bt/templates` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Public |
| Surface | Cloud API |
| Stability | stable |
| Support | supported |
| Deployment | cloud |

## When To Use

Use this endpoint when you need lists built-in behavior-tree templates. from the hosted API. It is part of the Behavior Trees surface and is intended to be the customer-facing contract for that capability.

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.
