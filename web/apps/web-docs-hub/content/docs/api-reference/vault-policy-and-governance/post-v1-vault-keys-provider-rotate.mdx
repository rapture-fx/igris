# POST /v1/vault/keys/:provider/rotate

Rotates a provider key. This endpoint belongs to the Vault, Policy, and Governance group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `POST` |
| Path | `/v1/vault/keys/:provider/rotate` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie or igris_ API key |
| Surface | Cloud API |
| Stability | stable |
| Support | supported |
| Deployment | cloud |

## When To Use

Use this endpoint when you need rotates a provider key. from the hosted API. It is part of the Vault, Policy, and Governance surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/v1/vault/keys/openai/rotate \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/vault/keys/openai/rotate', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/v1/vault/keys/openai/rotate", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::POST, "https://overture.igrisinertial.com/v1/vault/keys/openai/rotate")

        .send()
```
