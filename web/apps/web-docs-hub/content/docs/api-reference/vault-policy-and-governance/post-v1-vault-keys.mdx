# POST /v1/vault/keys

Stores a tenant-scoped provider credential for hosted routing. The raw upstream key is encrypted on write, and later reads only return masked metadata so the secret does not become part of the ordinary control-plane surface.

| Field | Value |
|---|---|
| Method | `POST` |
| Path | `/v1/vault/keys` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie or igris_ API key |
| Surface | Cloud API |
| Stability | stable |
| Support | core |
| Deployment | cloud |

## When To Use

Use this endpoint when you are setting up or rotating hosted routing credentials for a tenant. It is usually one of the first administrative calls you make before sending production inference traffic.

## Integration Guidance

Do not replay this request casually. Retry only on clearly transient 5xx or 429 responses, and make sure your client can tolerate the possibility that the first write may already have succeeded.

### Common Mistakes

- Sending a raw provider name that is not part of the currently supported public identifiers.
- Assuming a successful write means the key will ever be returned again in plaintext.
- Using ad hoc key labels that make later rotation and operational ownership harder to understand.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `provider` | `string` | Yes | Public provider identifier such as `openai` or `anthropic`. |
| `key_name` | `string` | Yes | Human-readable label for the key record. |
| `api_key` | `string` | Yes | Raw provider credential to encrypt and store. |

## Request Example

```json
{
  "provider": "openai",
  "key_name": "production",
  "api_key": "sk-live-redacted"
}
```

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/v1/vault/keys \
  -H "Authorization: Bearer $IGRIS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "provider": "openai",
  "key_name": "production",
  "api_key": "sk-live-redacted"
}'
```


### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"provider\": \"openai\",\n  \"key_name\": \"production\",\n  \"api_key\": \"sk-live-redacted\"\n}")

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/v1/vault/keys", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 201 | Created | The provider key was stored and masked metadata is returned. |
| 400 | Invalid request | The body was invalid, the provider was unsupported, or the upstream key failed validation. |
| 401 | Unauthorized | Session or API key auth failed. |
| 500 | Storage failed | The key vault could not persist the encrypted key. |
