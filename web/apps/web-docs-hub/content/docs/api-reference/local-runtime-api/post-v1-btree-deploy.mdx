# POST /v1/btree/deploy

Deploys a runtime behavior tree. This endpoint belongs to the Local Runtime API group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `POST` |
| Path | `/v1/btree/deploy` |
| Base URL | `http://localhost:8080` |
| Authentication | Runtime-config dependent |
| Surface | Local runtime |
| Stability | stable |
| Support | supported |
| Deployment | local |

## When To Use

Use this endpoint when the operation belongs on the local runtime rather than the hosted API. It is part of the Local Runtime API surface and should be called from the environment where the runtime is actually serving traffic.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Pointing the client at the hosted base URL even though this route is served by the local runtime.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Code Examples

### cURL

```bash
curl -X POST http://localhost:8080/v1/btree/deploy \
  -H "Authorization: Bearer $IGRIS_RUNTIME_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('http://localhost:8080/v1/btree/deploy', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_RUNTIME_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("POST", "http://localhost:8080/v1/btree/deploy", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_RUNTIME_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::POST, "http://localhost:8080/v1/btree/deploy")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_RUNTIME_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
