# POST /v1/btree/validate

Validates a behavior-tree document against the runtime schema before deploy or execution.

| Field | Value |
|---|---|
| Method | `POST` |
| Path | `/v1/btree/validate` |
| Base URL | `http://localhost:8080` |
| Authentication | Runtime-config dependent |
| Surface | Local runtime |
| Stability | stable |
| Support | core |
| Deployment | local |

## When To Use

Use this endpoint when the operation belongs on the local runtime rather than the hosted API. It is part of the Local Runtime API surface and should be called from the environment where the runtime is actually serving traffic.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Pointing the client at the hosted base URL even though this route is served by the local runtime.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `tree` | `object` | Yes | Behavior-tree definition in runtime JSON format. |

## Request Example

```json
{
  "tree": {
    "type": "sequence",
    "children": [
      {
        "type": "condition",
        "name": "battery_ok"
      },
      {
        "type": "action",
        "name": "dispatch_task"
      }
    ]
  }
}
```

### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"tree\": {\n    \"type\": \"sequence\",\n    \"children\": [\n      {\n        \"type\": \"condition\",\n        \"name\": \"battery_ok\"\n      },\n      {\n        \"type\": \"action\",\n        \"name\": \"dispatch_task\"\n      }\n    ]\n  }\n}")

req, err := http.NewRequest("POST", "http://localhost:8080/v1/btree/validate", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_RUNTIME_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```
