# POST /v1/runtime/execute

Executes a runtime task through the local execution boundary. This endpoint belongs to the Local Runtime API group and is documented here as a customer-facing contract with its auth model, request shape, and sample traffic.

## When To Use

Use this endpoint when the operation belongs on the local runtime rather than the hosted API. It is part of the Local Runtime API surface and should be called from the environment where the runtime is actually serving traffic.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Pointing the client at the hosted base URL even though this route is served by the local runtime.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `model` | `string` | Yes | Local or configured provider model. |
| `messages` | `array` | Yes | Conversation turns to execute. |
| `max_tokens` | `integer` | No | Optional generation limit. |
| `temperature` | `number` | No | Optional sampling temperature. |
| `stream` | `boolean` | No | Optional stream preference. |
| `mode` | `string` | No | Optional routing mode. |
| `tenant_id` | `string` | No | Optional tenant identifier forwarded by Overture. |
| `bounds` | `object` | No | Optional containment bounds. `X-Igris-Bounds` takes precedence. |

## Code Examples

### cURL

```bash
curl -X POST http://localhost:8080/v1/runtime/execute \
  -H "Authorization: Bearer $IGRIS_RUNTIME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "local",
  "messages": [
    {
      "role": "user",
      "content": "Run a local health summary."
    }
  ],
  "max_tokens": 128
}'
```


### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"model\": \"local\",\n  \"messages\": [\n    {\n      \"role\": \"user\",\n      \"content\": \"Run a local health summary.\"\n    }\n  ],\n  \"max_tokens\": 128\n}")

req, err := http.NewRequest("POST", "http://localhost:8080/v1/runtime/execute", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_RUNTIME_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust
