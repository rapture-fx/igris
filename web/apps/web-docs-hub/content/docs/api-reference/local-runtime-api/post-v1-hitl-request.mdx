## When To Use

Use this endpoint when you are working with Local Runtime API and are comfortable integrating against a preview surface. Confirm the current shape and rollout expectations before depending on it in a hard production path.

## Integration Guidance

Retry only on clearly transient 5xx or 429 responses, and prefer idempotent client behavior. For preview routes, avoid aggressive automatic replay until you have validated the behavior in your environment.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Pointing the client at the hosted base URL even though this route is served by the local runtime.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `task` | `string` | Yes | Human review task or decision prompt. |
| `context` | `object` | No | Context shown to the reviewer. |

## Request Example

```json
{
  "task": "Approve dispatch to loading bay 3",
  "context": {
    "confidence": 0.74
  }
}
```

## Code Examples

### cURL

```bash
curl -X POST http://localhost:8080/v1/hitl/request \
  -H "Authorization: Bearer $IGRIS_RUNTIME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "task": "Approve dispatch to loading bay 3",
  "context": {
    "confidence": 0.74
  }
}'
```

### JavaScript

```javascript
const response = await fetch('http://localhost:8080/v1/hitl/request', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_RUNTIME_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
  "task": "Approve dispatch to loading bay 3",
  "context": {
    "confidence": 0.74
  }
}),
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"task\": \"Approve dispatch to loading bay 3\",\n  \"context\": {\n    \"confidence\": 0.74\n  }\n}")

req, err := http.NewRequest("POST", "http://localhost:8080/v1/hitl/request", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_RUNTIME_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::POST, "http://localhost:8080/v1/hitl/request")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_RUNTIME_API_KEY")?))
        .json(&serde_json::json!({
  "task": "Approve dispatch to loading bay 3",
  "context": {
    "confidence": 0.74
  }
}))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Success | The request completed successfully. For streaming or download endpoints, the success response may be a stream or attachment rather than a JSON object. |
| 400 | Bad Request | The route was reached, but the request body, query string, or path parameter did not match the endpoint contract. |
| 401 | Unauthorized | Credentials were missing, expired, malformed, or not accepted by this route. |
| 429 | Too Many Requests | The caller exceeded the current throttle window and should wait before retrying. |
| 500 | Server Error | The server accepted the request contract but failed while processing it. |
