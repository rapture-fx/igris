# GET /v1/btree/events

Streams behavior-tree events. This endpoint belongs to the Local Runtime API group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/v1/btree/events` |
| Base URL | `http://localhost:8080` |
| Authentication | Runtime-config dependent |
| Surface | Local runtime |
| Stability | stable |
| Support | supported |
| Deployment | local |

## When To Use

Use this endpoint when the operation belongs on the local runtime rather than the hosted API. It is part of the Local Runtime API surface and should be called from the environment where the runtime is actually serving traffic.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Pointing the client at the hosted base URL even though this route is served by the local runtime.

## Code Examples

### cURL

```bash
curl -X GET http://localhost:8080/v1/btree/events \
  -H "Authorization: Bearer $IGRIS_RUNTIME_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('http://localhost:8080/v1/btree/events', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_RUNTIME_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "http://localhost:8080/v1/btree/events", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_RUNTIME_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "http://localhost:8080/v1/btree/events")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_RUNTIME_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
