# POST /api/v1/runtime/update

Queues a runtime update command. Use this to coordinate OTA rollout from the control plane rather than pulling binaries manually on every node.

| Field | Value |
|---|---|
| Method | `POST` |
| Path | `/api/v1/runtime/update` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie |
| Surface | Fleet management |
| Stability | stable |
| Support | supported |
| Deployment | hybrid |

## When To Use

Use this endpoint when the workflow spans both the hosted control plane and one or more runtimes. It belongs to the Runtime Distribution & Fleet Coordination area of the product and is most useful when you are coordinating runtime distribution, fleet state, or device operations.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Treating a hybrid coordination route like a local-only runtime call without the required tenant context or fleet state.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `runtime_ids` | `array` | Yes | One or more runtime IDs to target. |
| `version` | `string` | Yes | Target runtime version or release channel. |

## Request Example

```json
{
  "runtime_ids": [
    "rt_01HV94AS6G98PZ2YH"
  ],
  "version": "runtime-v1.6.0"
}
```

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/api/v1/runtime/update \
  -H "Cookie: better-auth.session_token=$IGRIS_SESSION_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "runtime_ids": [
    "rt_01HV94AS6G98PZ2YH"
  ],
  "version": "runtime-v1.6.0"
}'
```

### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"runtime_ids\": [\n    \"rt_01HV94AS6G98PZ2YH\"\n  ],\n  \"version\": \"runtime-v1.6.0\"\n}")

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/api/v1/runtime/update", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Cookie", "better-auth.session_token=" + os.Getenv("IGRIS_SESSION_TOKEN"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```
