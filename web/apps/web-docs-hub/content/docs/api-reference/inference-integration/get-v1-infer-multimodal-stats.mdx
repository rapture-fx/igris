# GET /v1/infer/multimodal/stats

Multimodal request statistics. This endpoint belongs to the Inference & Integration group and is documented here so customers can understand the contract, auth model, and verified sample traffic without reading the server implementation.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/v1/infer/multimodal/stats` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session or API key |
| Surface | Cloud API |
| Stability | preview |
| Support | preview |
| Deployment | cloud |

## When To Use

Use this endpoint when you need multimodal request statistics. and you are comfortable integrating against a preview surface. Confirm the current shape and rollout expectations before depending on it in a hard production path.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/infer/multimodal/stats \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/infer/multimodal/stats', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/infer/multimodal/stats", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

