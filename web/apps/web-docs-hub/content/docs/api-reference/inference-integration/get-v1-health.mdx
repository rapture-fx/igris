# GET /v1/health

Simple health probe for the local runtime API. Use it for readiness checks and to confirm the local process is serving traffic.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/v1/health` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Public |
| Surface | Cloud API |
| Stability | stable |
| Support | core |
| Deployment | cloud |

## When To Use

Use this endpoint when you need health check for inference availability. from the hosted API. It is part of the Inference & Integration surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/health", body)
if err != nil {
	log.Fatal(err)
}


resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

