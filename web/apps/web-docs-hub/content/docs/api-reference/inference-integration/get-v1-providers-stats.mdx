# GET /v1/providers/stats

Exposes high-level provider health and routing telemetry so you can understand latency, error rate, and current selection pressure.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/v1/providers/stats` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Public |
| Surface | Cloud API |
| Stability | stable |
| Support | supported |
| Deployment | cloud |

## When To Use

Use this endpoint when you need provider latency, health, and routing statistics. from the hosted API. It is part of the Inference & Integration surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.
