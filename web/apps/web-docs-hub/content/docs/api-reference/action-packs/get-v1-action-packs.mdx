# GET /v1/action-packs

Lists built-in Action Packs that Igris ships for onboarding. Each pack is a small manifest of registered actions — not a connector marketplace and not a raw task runner. Pack manifests contain no secrets; install only registers action definitions in your tenant.

## When To Use

Use this endpoint (or `igris packs list`) before installing a pack, or when building an onboarding flow that should show what safe starter actions are available.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.

## Notes

- Today the only built-in pack is `starter`. It registers `demo.echo`, `demo.fail_once`, and `demo.needs_approval` — all `mock_demo` actions with no external provider credentials.
- Action Packs are not a connector marketplace. External provider packs such as Stripe, GitHub, or Slack are not built-in yet.
- After install, run actions through `POST /v1/actions/:name/run` or MCP `call_action` like any other registered action.

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/action-packs \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/action-packs', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/action-packs", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/action-packs")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Pack catalog | Built-in Action Packs available for install are returned. |
| 401 | Unauthorized | Credentials were missing, expired, or not accepted. |
