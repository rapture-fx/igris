# GET /v1/receipts

Lists execution receipts for the tenant from the coordination layer. This is the read surface for audit-oriented views where you care about the execution record itself rather than only the timeline around it.

| Field | Value |
|---|---|
| Method | `GET` |
| Path | `/v1/receipts` |
| Base URL | `https://overture.igrisinertial.com` |
| Authentication | Session cookie or igris_ API key |
| Surface | Cloud API |
| Stability | stable |
| Support | core |
| Deployment | cloud |

## When To Use

Use this endpoint when you need to review receipt records, prepare export jobs, or feed an audit-oriented UI that is centered on execution artifacts.

## Integration Guidance

Safe to retry on transient 5xx or 429 responses. Prefer narrower filters over repeated broad scans if the query is being used interactively.

### Common Mistakes

- Using receipt listing when a history timeline would be easier to interpret for the question at hand.
- Treating the list response like a bulk export instead of using the dedicated export route.

## Query Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `limit` | `integer` | No | Maximum number of receipts to return. |
| `from` | `string` | No | RFC3339 lower time bound. |
| `to` | `string` | No | RFC3339 upper time bound. |
| `agent_id` | `string` | No | Optional agent filter. |
| `violations_only` | `boolean` | No | Restrict results to violation receipts. |

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/receipts?limit=50&violations_only=false \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/receipts?limit=50&violations_only=false', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/receipts?limit=50&violations_only=false", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/receipts?limit=50&violations_only=false")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
