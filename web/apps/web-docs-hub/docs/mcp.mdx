# MCP (Model Context Protocol)

Igris supports the Model Context Protocol (MCP), enabling agents to share structured context across tool calls, sessions, and — with MCP Swarm Mode — across multiple runtime instances.

Use this page as the MCP overview. For the more specific product surfaces, continue with:

## What MCP Does

MCP is a JSON-RPC protocol for structured context management between an LLM and its host environment. Igris implements an MCP server inside the runtime and exposes it via the coordination layer API, so your application can:

- Read and write structured context that survives across tool calls
- Share context between multiple agents on the same device
- (With Swarm Mode) share context across devices on the same network

---

## POST /v1/mcp

Proxy a JSON-RPC request to the connected runtime's MCP server.

```bash
curl -X POST https://overture.igrisinertial.com/v1/mcp \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "context/write",
    "params": {
      "key": "mission_state",
      "value": {"step": 3, "status": "navigating", "target": "zone-b"}
    },
    "id": 1
  }'
```

The request is forwarded to the connected runtime. The runtime's MCP server processes it and returns the result.

**Common MCP methods:**

| Method | Description |
|---|---|
| `context/write` | Write a key-value pair to the context store |
| `context/read` | Read a value by key |
| `context/list` | List all context keys |
| `context/delete` | Delete a key |
| `tools/list` | List available tools |
| `tools/call` | Call a tool by name |

---

## POST /v1/mcp/stream

Server-Sent Events version for streaming MCP responses. Connect with `EventSource` and `withCredentials: true`.

```javascript
const es = new EventSource('https://overture.igrisinertial.com/v1/mcp/stream', {
  withCredentials: true,
});

es.onmessage = (event) => {
  const msg = JSON.parse(event.data);
  console.log('MCP event:', msg);
};
```

Use the stream endpoint when the MCP method returns incremental results (e.g., tool calls with streaming output).

## MCP Swarm Mode

When multiple runtime instances run on the same network with MCP Swarm Mode enabled, context written by one instance is immediately readable by all others.

**How it works:**
- Instances auto-discover each other via mDNS
- Context is replicated across the swarm with AES-256-GCM encryption
- Any instance can answer a `context/read` request, even if the key was written by a different instance

**Configuration (igris.toml):**
```toml
[mcp_swarm]
enabled = true
discovery = "mdns"
encryption_key_path = "/path/to/swarm.key"
```

**Use cases:**
- Robot coordination: one arm writes its position, another reads it
- High availability: context survives individual instance failures
- Distributed planning: agents on different nodes share task state
