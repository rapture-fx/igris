# Behavior Trees

Igris includes a production-grade behavior tree engine that combines deterministic control flow with LLM-powered adaptive reasoning. Use it to build agents that follow structured logic but can invoke an LLM when the situation requires judgment.

---

## Why Behavior Trees

Traditional behavior trees are deterministic: the same inputs always produce the same outputs. This is ideal for safety-critical systems but breaks down when the task requires language understanding or contextual reasoning.

Igris behavior trees let you mix both:
- **Deterministic nodes** — sequence, selector, condition, action — execute reliably and predictably
- **LLM nodes** — call a local or cloud model when the situation requires judgment

The result: agents that are auditable and safe by default, with AI where it adds value.

---

## Node Types

| Type | JSON `type` value | Behavior |
|---|---|---|
| `Sequence` | `"sequence"` | Runs children left to right; stops on first failure |
| `Selector` | `"selector"` | Runs children left to right; stops on first success |
| `Condition` | `"condition"` | Returns success/failure based on a blackboard key check |
| `Action` | `"action"` | Executes a named tool with optional args |
| `LLM` | `"llm_node"` | Calls a model; succeeds when the model returns a result |

## Quick Example

```json
{
  "type": "sequence",
  "name": "shutdown-guard",
  "children": [
    {
      "type": "condition",
      "name": "check_temp",
      "key": "sensor.temperature",
      "expected": 80
    },
    {
      "type": "llm_node",
      "name": "ask_model",
      "prompt": "The temperature is high. Should we shut down the process? Reply yes or no.",
      "model": "phi3"
    },
    {
      "type": "action",
      "name": "shutdown",
      "tool": "http_post",
      "args": { "url": "http://localhost:9000/shutdown" }
    }
  ]
}
```

This tree: checks a sensor value, asks the LLM whether to act, and only shuts down the process if both the condition and the model agree.

## Deploying a Tree

```bash
# Deploy a behavior tree to a running engine
curl -X POST http://localhost:8080/v1/btree/deploy \
  -H "Content-Type: application/json" \
  -d @my-tree.json

# Run the tree once
curl -X POST http://localhost:8080/v1/btree/run \
  -H "Content-Type: application/json" \
  -d '{"tree_id": "shutdown-guard", "context": {"sensor": {"temperature": 92}}}'

# Run on a tick loop (e.g. every 100ms)
curl -X POST http://localhost:8080/v1/btree/run \
  -d '{"tree_id": "shutdown-guard", "tick_interval_ms": 100}'
```

## Using the SDK

```typescript
import { Runtime, BehaviorTree, SequenceNode, ConditionNode, ActionNode } from '@igris-inertial/sdk';

const runtime = new Runtime({ localUrl: 'http://localhost:8080' });

const tree = BehaviorTree.fromJson(
  new SequenceNode('shutdown-guard', [
    new ConditionNode('check_temp', 'sensor.temperature', '80'),
    new ActionNode('shutdown', 'http_post', { url: 'http://localhost:9000/shutdown' }),
  ]).toJSON(),
  runtime,
);

const result = await tree.validate();
// { valid: true, root_type: 'sequence' }

const execution = await tree.run({ context: { 'sensor.temperature': 92 } });
console.log(execution.status); // 'success' | 'failure'
```

```python
from igris import Runtime, RuntimeConfig
from igris.btree import BehaviorTree, Sequence, Condition, Action

runtime = Runtime(RuntimeConfig(local_url="http://localhost:8080"))

tree = BehaviorTree.from_nodes(
    Sequence("shutdown-guard", [
        Condition("check_temp", key="sensor.temperature", expected=80),
        Action("shutdown", tool="http_post", args={"url": "http://localhost:9000/shutdown"}),
    ]),
    runtime,
)

result = tree.validate()
execution = tree.run(context={"sensor.temperature": 92})
print(execution["status"])  # 'success' | 'failure'
```

## Production Characteristics

- Trees are validated at deploy time — malformed trees are rejected before execution
- Each tick produces an execution receipt with the node path taken and outcome
- LLM node calls are subject to the same capability gates as any other tool call
- Trees can be hot-reloaded without restarting the engine
