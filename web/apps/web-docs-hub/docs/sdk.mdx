# SDKs

Igris exposes an OpenAI-compatible API. Any existing OpenAI SDK works without modification — just change the base URL. For richer access to routing metadata, provider management, fleet, and audit, official Igris SDKs are available in four languages.

---

## Quick Setup

All SDKs connect to the same endpoint:

```
https://api.igrisinertial.com/v1
```

For local execution, point to your engine's address (default `http://localhost:8080`).

---

## JavaScript / TypeScript

**Install:**

```bash
npm install @igris-inertial/sdk
```

**Basic inference:**

```typescript
import { IgrisClient } from '@igris-inertial/sdk';

const client = new IgrisClient({
  baseUrl: 'https://api.igrisinertial.com',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.chatCompletion({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello' }],
});

console.log(response.choices[0].message.content);
console.log(response.metadata?.provider);   // 'anthropic'
console.log(response.metadata?.cost_usd);   // 0.00021
```

**Cost-optimized routing:**

```typescript
const response = await client.infer({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Summarize this document.' }],
  optimize_for: 'cost',
});
```

**OpenAI SDK (zero code changes):**

```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://api.igrisinertial.com/v1',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.chat.completions.create({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

## Python

**Install:**

```bash
pip install igris-inertial
```

**Basic inference:**

```python
from igris import IgrisClient

client = IgrisClient(
    base_url="https://api.igrisinertial.com",
    api_key=os.environ["IGRIS_API_KEY"],
)

response = client.chat_completion({
    "model": "gpt-4",
    "messages": [{"role": "user", "content": "Hello"}],
})

print(response.choices[0].message.content)
print(response.metadata.provider)   # 'openai'
print(response.metadata.cost_usd)   # 0.00034
```

**With optimize_for and provider pin:**

```python
response = client.infer({
    "model": "gpt-4",
    "messages": [{"role": "user", "content": "Translate to French."}],
    "optimize_for": "latency",
    "provider": "anthropic",
})
```

**OpenAI SDK (zero code changes):**

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.igrisinertial.com/v1",
    api_key=os.environ["IGRIS_API_KEY"],
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello"}],
)
```

## Go

**Install:**

```bash
go get github.com/igris-inertial/go-sdk
```

**Basic inference:**

```go
import (
    igris "github.com/igris-inertial/go-sdk"
)

client := igris.NewClient(
    "https://api.igrisinertial.com",
    os.Getenv("IGRIS_API_KEY"),
)

resp, err := client.ChatCompletion(ctx, &igris.InferRequest{
    Model: "gpt-4",
    Messages: []igris.Message{
        {Role: "user", Content: "Hello"},
    },
})
if err != nil {
    log.Fatal(err)
}

fmt.Println(resp.Choices[0].Message.Content)
```

**With options:**

```go
client := igris.NewClient(
    "https://api.igrisinertial.com",
    os.Getenv("IGRIS_API_KEY"),
    igris.WithTimeout(10*time.Second),
    igris.WithTenantID("tenant-abc"),
)

resp, err := client.Infer(ctx, &igris.InferRequest{
    Model:       "gpt-4",
    Messages:    []igris.Message{{Role: "user", Content: "Hello"}},
    OptimizeFor: "cost",
})
```

## Rust

**Add to `Cargo.toml`:**

```toml
[dependencies]
igris-inertial = "2.2"
tokio = { version = "1", features = ["rt-multi-thread", "macros"] }
```

**Basic inference:**

```rust
use igris_inertial::{IgrisClient, types::{InferRequest, Message}};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = IgrisClient::new(
        "https://api.igrisinertial.com",
        std::env::var("IGRIS_API_KEY")?,
    )?;

    let request = InferRequest {
        model: "gpt-4".to_string(),
        messages: vec![Message {
            role: "user".to_string(),
            content: "Hello".to_string(),
        }],
        ..Default::default()
    };

    let response = client.chat_completion(&request).await?;
    println!("{}", response.choices[0].message.content);

    Ok(())
}
```

**Builder pattern:**

```rust
let client = IgrisClient::builder("https://api.igrisinertial.com")
    .api_key(std::env::var("IGRIS_API_KEY")?)
    .timeout(std::time::Duration::from_secs(10))
    .tenant_id("tenant-abc")
    .build()?;
```

## Request Options

All SDKs support the same core request fields:

| Field | Type | Description |
|---|---|---|
| `model` | string | Model to request (e.g. `gpt-4`, `claude-3-haiku`) |
| `messages` | array | Conversation messages with `role` and `content` |
| `provider` | string | Pin to a specific provider (optional) |
| `optimize_for` | string | `"latency"`, `"cost"`, or `"quality"` (optional) |
