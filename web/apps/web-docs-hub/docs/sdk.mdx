# SDKs

> **Private Beta** — The Igris SDKs are not yet published to public registries (PyPI, npm, crates.io, pkg.go.dev). To deploy an agent today, use the [install script](/docs/quickstart) — it is the only working installation path.
>
> SDK access is available via GitHub. Contact [support@igrisinertial.com](mailto:support@igrisinertial.com) or join the beta at [console.igrisinertial.com](https://console.igrisinertial.com).

---

Igris exposes an OpenAI-compatible API. Any existing OpenAI SDK works without modification — just change the base URL. For richer access to routing metadata, provider management, fleet, and audit, official Igris SDKs are available in four languages.

> **Note:** Code examples below show the planned SDK API. Subject to change before public release.

---

## OpenAI-Compatible (Works Today)

Any OpenAI SDK works against the Igris endpoint with zero code changes:

**Python:**

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://overture.igrisinertial.com/v1",
    api_key=os.environ["IGRIS_API_KEY"],
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

**JavaScript / TypeScript:**

```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://overture.igrisinertial.com/v1',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.chat.completions.create({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello' }],
});
console.log(response.choices[0].message.content);
```

**Install OpenAI SDK:**

```bash
pip install openai          # Python
npm install openai          # Node.js
```

## Igris Native SDKs (Private Beta)

> These packages are **not yet published**. Request access at [support@igrisinertial.com](mailto:support@igrisinertial.com).

### JavaScript / TypeScript

```typescript
import { IgrisClient } from '@igris-inertial/sdk';

const client = new IgrisClient({
  baseUrl: 'https://overture.igrisinertial.com',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.infer({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello' }],
  optimize_for: 'cost',
});

console.log(response.choices[0].message.content);
console.log(response.metadata?.provider);   // 'anthropic'
console.log(response.metadata?.cost_usd);   // 0.00021
```

### Python

```python
import os
from igris import IgrisClient

client = IgrisClient(
    base_url="https://overture.igrisinertial.com",
    api_key=os.environ["IGRIS_API_KEY"],
)

response = client.infer({
    "model": "gpt-4",
    "messages": [{"role": "user", "content": "Hello"}],
    "optimize_for": "latency",
})

print(response.choices[0].message.content)
print(response.metadata.provider)   # 'openai'
```

### Go

```go
import (
    "context"
    igris "github.com/igris-inertial/go-sdk"
)

client := igris.NewClient(
    "https://overture.igrisinertial.com",
    os.Getenv("IGRIS_API_KEY"),
)

resp, err := client.Infer(context.Background(), &igris.InferRequest{
    Model: "gpt-4",
    Messages: []igris.Message{
        {Role: "user", Content: "Hello"},
    },
})
if err != nil {
    log.Fatal(err)
}

fmt.Println(resp.Choices[0].Message.Content)
```

### Rust

```rust
use igris_inertial::{IgrisClient, InferRequest, Message};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = IgrisClient::builder("https://overture.igrisinertial.com")
        .api_key(std::env::var("IGRIS_API_KEY")?)
        .build()?;

    let response = client.infer(&InferRequest {
        model: "gpt-4".to_string(),
        messages: vec![Message {
            role: "user".to_string(),
            content: "Hello".to_string(),
            ..Default::default()
        }],
        ..Default::default()
    }).await?;

    println!("{}", response.choices[0].message.content);
    Ok(())
}
```

## Request Options

All SDKs support the same core request fields:

| Field | Type | Description |
|---|---|---|
| `model` | string | Model to request (e.g. `gpt-4`, `claude-3-haiku`) |
| `messages` | array | Conversation messages with `role` and `content` |
| `provider` | string | Pin to a specific provider (optional) |
| `optimize_for` | string | `"latency"`, `"cost"`, or `"quality"` (optional) |
