# SDKs

Igris supports two integration paths:

- **OpenAI-compatible clients** for the fastest path to production
- **Native Igris SDKs** when you need routing metadata, receipt helpers, vault operations, or fleet APIs

The recommendation is straightforward:

- Start with the OpenAI-compatible API if you want the shortest path to a working integration
- Move to a native SDK when you need Igris-specific product features and a stronger typed client

The native first-class SDKs today are JavaScript/TypeScript, Go, and Rust. Python exists in-repo but remains preview. Java, C#, and Ruby should use the OpenAI-compatible API today rather than being treated as native SDK targets.

## OpenAI-Compatible Clients

Any OpenAI SDK can call Igris by changing the base URL.

**Python**

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://overture.igrisinertial.com/v1",
    api_key=os.environ["IGRIS_API_KEY"],
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello"}],
)

print(response.choices[0].message.content)
```

**JavaScript / TypeScript**

```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://overture.igrisinertial.com/v1',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.chat.completions.create({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello' }],
});

console.log(response.choices[0].message.content);
```

Use this path for Java, C#, Ruby, Python, or any other language where you already have an OpenAI-compatible client and do not need the native Igris SDK surface.

## Native SDKs

### JavaScript / TypeScript

```typescript
import { IgrisClient } from '@igris-inertial/sdk';

const client = new IgrisClient({
  baseUrl: 'https://overture.igrisinertial.com',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.infer({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello' }],
});

console.log(response.choices[0].message.content);
```

### Go

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    igris "github.com/igris-inertial/go-sdk"
)

func main() {
    client := igris.NewClient(
        "https://overture.igrisinertial.com",
        os.Getenv("IGRIS_API_KEY"),
    )

    resp, err := client.Infer(context.Background(), &igris.InferRequest{
        Model: "gpt-4",
        Messages: []igris.Message{
            {Role: "user", Content: "Hello"},
        },
    })
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(resp.Choices[0].Message.Content)
}
```

### Rust

```rust
use igris_inertial::{IgrisClient, InferRequest, Message};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = IgrisClient::builder("https://overture.igrisinertial.com")
        .api_key(std::env::var("IGRIS_API_KEY")?)
        .build()?;

    let response = client
        .infer(&InferRequest {
            model: "gpt-4".to_string(),
            messages: vec![Message {
                role: "user".to_string(),
                content: "Hello".to_string(),
                content_parts: None,
            }],
            ..Default::default()
        })
        .await?;

    println!("{}", response.choices[0].message.content);
    Ok(())
}
```

### Python Preview

The Python SDK is present in the repository and can be used experimentally:

```python
from igris import IgrisClient

client = IgrisClient(
    base_url="https://overture.igrisinertial.com",
    api_key="YOUR_IGRIS_API_KEY",
)
```

Treat the Python package as preview until it is explicitly promoted to first-class support. For production Python integrations today, the OpenAI-compatible API remains the safer default.

## Request Contract

The core infer request fields are shared across native SDKs:

| Field | Type | Description |
|---|---|---|
| `model` | string | Upstream model name or local runtime model |
| `messages` | array | Conversation messages with `role` and `content` |
| `provider` | string | Optional provider pin |
| `optimize_for` | string | Optional routing hint such as `"latency"` or `"cost"` |

When you need the most portable path across languages, default to the OpenAI-compatible client surface. When you need the strongest supported native contract, choose JavaScript/TypeScript, Go, or Rust.
