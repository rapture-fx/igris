# API Reference

This reference covers the public API for Igris as one product.

- Use the **cloud API** at `https://overture.igrisinertial.com` for hosted coordination, account management, fleet operations, receipts, and policy.
- Use the **local runtime endpoint** at `http://localhost:8080` by default when Igris is executing locally in your environment.

The endpoint catalog below is grouped by capability, with dedicated pages for each endpoint and guide pages for authentication, errors, and rate limits.
