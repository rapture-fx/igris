# API Reference

Igris exposes two customer-facing API surfaces:

- The **cloud control plane** at `https://overture.igrisinertial.com`
- The **local runtime API** at `http://localhost:8080` by default

This reference is generated from the live route registrations in `igris-overture` and `igris-runtime`, then annotated with auth and stability notes. It is the contract for the current shipped codebase, not a roadmap.
