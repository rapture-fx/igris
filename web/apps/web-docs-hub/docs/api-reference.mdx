# API Reference

Igris exposes two API surfaces: the inference API (OpenAI-compatible) and the management API (Igris-native). Both are available at `api.igrisinertial.com`. For local execution engine APIs, replace the base URL with your engine's address (default `http://localhost:8080`).

---

## Authentication

All API requests require a Bearer token:

```bash
curl https://api.igrisinertial.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4", "messages": [{"role": "user", "content": "Hello"}]}'
```

## Inference API

The inference API is OpenAI-compatible. Any existing code using the OpenAI SDK works by changing only the base URL.

### POST /v1/chat/completions

Run a chat completion.

**Request:**
```json
{
  "model": "gpt-4",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello"}
  ],
  "provider": "anthropic",
  "optimize_for": "cost"
}
```

**Additional fields (Igris-native):**

| Field | Type | Description |
|---|---|---|
| `provider` | string | Pin to a specific provider (optional) |
| `optimize_for` | string | `"cost"`, `"latency"`, or `"quality"` |
| `tenant_id` | string | Override tenant for this request |

**Response:**
```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "model": "gpt-4",
  "choices": [{"message": {"role": "assistant", "content": "Hello!"}}],
  "metadata": {
    "provider": "anthropic",
    "model_used": "claude-3-haiku",
    "cost_usd": 0.00021,
    "routing_decision": "thompson-sampling",
    "fallback": false
  }
}
```

### POST /v1/completions

Legacy text completion endpoint. Same authentication and metadata fields.

## Management API

### Providers & Keys

| Endpoint | Method | Description |
|---|---|---|
| `/v1/vault/keys` | GET | List configured provider keys |
| `/v1/vault/keys` | POST | Add a provider key |
| `/v1/vault/keys/{provider}` | DELETE | Remove a provider key |

```bash
# Add an OpenAI key
curl -X POST https://api.igrisinertial.com/v1/vault/keys \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"provider": "openai", "key": "sk-..."}'
```

### Policies

| Endpoint | Method | Description |
|---|---|---|
| `/v1/policies` | GET | List policies |
| `/v1/policies` | POST | Create a policy |
| `/v1/policies/{name}` | GET | Get a policy |
| `/v1/policies/{name}` | PATCH | Update a policy |
| `/v1/policies/{name}/versions` | GET | List policy versions |
| `/v1/policies/{name}/rollback` | POST | Roll back to a version |

### Fleet (Execution Engine Instances)

| Endpoint | Method | Description |
|---|---|---|
| `/api/v1/runtime/register` | POST | Register an instance |
| `/api/v1/runtime/instances` | GET | List all instances |
| `/api/v1/runtime/instances/{id}` | GET | Get instance details |
| `/api/v1/runtime/config/push` | POST | Push config to instances |
| `/api/v1/runtime/update` | POST | Trigger OTA update |

### Receipts (Local Engine)

| Endpoint | Method | Description |
|---|---|---|
| `/v1/receipts` | GET | List execution receipts |
| `/v1/receipts/{request_id}` | GET | Get a specific receipt |
| `/v1/receipts/export` | GET | Export receipts (JSONL/CSV/Parquet) |

## Local Engine API

The execution engine runs an OpenAI-compatible API at `http://localhost:8080` by default.

| Endpoint | Description |
|---|---|
| `GET /health` | Health check |
| `GET /metrics` | Prometheus metrics |
| `POST /v1/chat/completions` | Chat completion |
| `GET /v1/receipts` | List receipts |
| `GET /v1/receipts/{id}` | Get receipt |
| `POST /v1/btree/deploy` | Deploy a behavior tree |
| `POST /v1/btree/run` | Run a behavior tree |

## Rate Limits

| Tier | Requests/minute | Tokens/minute |
|---|---|---|
| Seed | 60 | 100,000 |
| Horizon | 600 | 1,000,000 |
| Infinite | 6,000 | 10,000,000 |

Rate limit headers are included in every response:
- `X-RateLimit-Limit`: requests per minute
- `X-RateLimit-Remaining`: remaining requests in current window
- `X-RateLimit-Reset`: UTC timestamp when the window resets
