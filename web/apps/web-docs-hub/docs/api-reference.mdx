# API Reference

Igris exposes two customer-facing API surfaces:

- The **cloud control plane** at `https://overture.igrisinertial.com`
- The **local runtime API** at `http://localhost:8080` by default

This reference documents the current customer API surface for the shipped product. Endpoint pages include coverage signals for each route.
