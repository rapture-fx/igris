# Key Management

Igris stores and manages cloud provider API keys on your behalf. Keys are encrypted at rest, scoped to your account, and never exposed in logs or API responses.

---

## Adding Provider Keys

Add your provider API keys through the console at [console.igrisinertial.com/settings/keys](https://console.igrisinertial.com/settings/keys).

Supported providers:

| Provider | Notes |
|---|---|
| OpenAI | Standard `sk-…` key |
| Anthropic | Standard `sk-ant-…` key |
| xAI (Grok) | API key from console.x.ai |
| Google (Gemini) | API key from Google AI Studio |
| Cohere | API key from dashboard.cohere.com |
| Azure OpenAI | Endpoint + API key |

---

## Key Validation

When you save a key, Igris immediately tests it against the provider's live API before storing it. If validation fails, the key is rejected and you'll see the provider's error message.

Keys are re-validated periodically in the background. A key that becomes invalid (revoked, quota exhausted) is flagged in the console and excluded from routing until you replace it.

---

## Rotating a Provider Key

To replace a key — for example, after a rotation on the provider side:

1. Go to **Settings → Keys** in the console
2. Click **Replace** next to the provider
3. Paste the new key
4. Igris validates the new key before replacing the old one

The old key stays active until the new one passes validation. Rotation is atomic — there is no window where neither key is active.

---

## Removing a Key

Removing a key from the vault immediately stops Igris from routing requests to that provider. If you remove your only key for a provider, requests targeting that provider will fail until a new key is added.

---

## Security Properties

- Keys are encrypted before storage — they are never stored in plaintext
- Keys are scoped to your account; no other tenant can access them
- The masked key (e.g. `sk-****abcd`) is the only form ever returned by the API
- All key operations (add, rotate, remove, validate) are recorded in your audit log
