# Quick Start

Get Igris executing AI workloads in a few minutes.

---

## Cloud (Fastest)

Use the cloud API. No infrastructure to deploy — change one URL in your existing code.

**Time to first request: ~2 minutes**

### Step 1: Get an API key

Sign up at [app.igrisinertial.com](https://app.igrisinertial.com) and create an API key.

### Step 2: Point your SDK at Igris

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.igrisinertial.com/v1",
    api_key="your-igris-api-key"
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello"}]
)

print(response.choices[0].message.content)
# Routing metadata is also available:
# response.metadata → {"provider": "anthropic", "cost_usd": 0.00021, ...}
```

### Step 3: Add provider keys

Add the API keys for the cloud providers you want to use:

```bash
curl -X POST https://api.igrisinertial.com/v1/vault/keys \
  -H "Authorization: Bearer YOUR_IGRIS_KEY" \
  -H "Content-Type: application/json" \
  -d '{"provider": "openai", "key": "sk-..."}'
```

Igris now routes requests across your configured providers automatically — with failover, cost optimization, and execution metadata on every response.

## Local / Edge (No Internet Required)

Deploy the execution engine on your hardware for offline inference, signed receipts, and governed execution.

**Time to first request: ~10 minutes**

### Step 1: Download the execution engine

```bash
# Linux / macOS
curl -L https://github.com/Igris-inertial/igris-runtime/releases/latest/download/igris-runtime-$(uname -s)-$(uname -m).tar.gz | tar xz
```

### Step 2: Download a local model

```bash
cd igris-runtime
./download-model.sh phi3-mini
```

Downloads Phi-3 Mini (~2.3GB). Runs on most hardware including Raspberry Pi.

### Step 3: Start the engine

```bash
./igris-runtime --config config.json
```

Engine starts on `http://localhost:8080`. Test it:

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "messages": [{"role": "user", "content": "What is 2+2?"}]
  }'
```

Your application gets a response whether or not the internet is available. Every execution produces a signed receipt.

### Step 4: Point your application at the engine

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="not-required"
)

response = client.chat.completions.create(
    model="phi3",
    messages=[{"role": "user", "content": "Hello"}]
)
```

## Hybrid (Cloud + Local Fallback)

Run the execution engine locally and register it with the cloud coordination layer. Cloud providers handle most requests; the local engine handles requests when cloud is unavailable.

### 1. Deploy the engine (same as Local above)

Follow the Local / Edge steps to get the engine running.

### 2. Register the engine

```bash
curl -X POST https://api.igrisinertial.com/api/v1/runtime/register \
  -H "Authorization: Bearer YOUR_IGRIS_KEY" \
  -d '{
    "name": "local-engine",
    "endpoint": "http://your-server-ip:8080"
  }'
```

### 3. Configure routing policy

```json
{
  "routing": {
    "primary": ["openai", "anthropic"],
    "fallback": ["runtime:local-engine"]
  }
}
```

Cloud providers handle most requests. When they are unavailable, the local engine takes over automatically.
