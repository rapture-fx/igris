# Quick Start

Get Igris executing AI workloads in a few minutes.

---

## Install the Runtime

The fastest way to get started on any platform:

```bash
curl -sSL https://igris.sh/install | bash
```

Detects your platform (Linux x86-64/ARM64, macOS Apple Silicon/Intel, Windows), downloads the correct binary, verifies the checksum, and installs to `/usr/local/bin/igris-runtime`.

> **Manual download:** If scripts are restricted, download the binary directly from **Fleet → Downloads** in the console.

---

## Option A — Cloud API (No local setup)

Use the cloud API directly. No runtime to deploy — just change one URL in your existing code.

**Time to first request: ~2 minutes**

### Step 1: Sign up and get an API key

Sign up at [app.igrisinertial.com](https://app.igrisinertial.com) and create an API key from the dashboard.

### Step 2: Add your provider keys

Add the API keys for the AI providers you want to route across:

```bash
curl -X POST https://api.igrisinertial.com/v1/vault/keys \
  -H "Authorization: Bearer YOUR_IGRIS_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "openai",
    "key_name": "Production",
    "api_key": "sk-..."
  }'
```

Repeat for each provider (anthropic, google, deepseek, etc.).

### Step 3: Point your SDK at Igris

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.igrisinertial.com/v1",
    api_key="your-igris-api-key"
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello"}]
)

print(response.choices[0].message.content)
# response.metadata → {"provider": "anthropic", "cost_usd": 0.00021, ...}
```

Igris routes requests across your configured providers automatically — with failover, cost optimization, and signed execution metadata on every response.

## Option B — Local / Edge (No internet required)

Run the runtime on your own hardware for offline inference, signed receipts, and governed execution.

**Time to first request: ~10 minutes**

### Step 1: Install the runtime

```bash
curl -sSL https://igris.sh/install | bash
```

### Step 2: Set credentials

Get your keys from **Settings → License** and **Settings → Keys** in the console:

```bash
export IGRIS_LICENSE_KEY=lic_…
export IGRIS_API_KEY=igris_…
```

### Step 3: Start the runtime

```bash
igris-runtime serve
```

The runtime validates your license, registers itself with your fleet, and appears in **Fleet → Devices** within a minute.

### Step 4: Point your application at the runtime

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="not-required"
)

response = client.chat.completions.create(
    model="phi3",
    messages=[{"role": "user", "content": "Hello"}]
)
```

Every execution produces a signed receipt. Your application gets a response whether or not the internet is available.

## Option C — Hybrid (Cloud + Local Fallback)

Run the runtime locally and register it with the cloud layer. Cloud providers handle most requests; the local runtime takes over when cloud is unavailable.

### Step 1: Deploy the runtime

Follow Option B steps 1–3 to install and start the runtime.

### Step 2: Register the runtime

The runtime registers itself automatically on startup using your `IGRIS_API_KEY`. To register manually:

```bash
curl -X POST https://api.igrisinertial.com/api/v1/runtime/register \
  -H "Authorization: Bearer YOUR_IGRIS_API_KEY" \
  -d '{
    "name": "local-runtime",
    "endpoint": "http://your-server-ip:8080"
  }'
```

### Step 3: Configure routing policy

```json
{
  "routing": {
    "primary": ["openai", "anthropic"],
    "fallback": ["runtime:local-runtime"]
  }
}
```

Cloud providers handle most requests. When unavailable, the local runtime takes over automatically.
