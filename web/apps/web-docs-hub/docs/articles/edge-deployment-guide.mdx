# Deploying Igris on Edge Devices

Running `igris-runtime` on edge hardware gives you local inference, local policy enforcement, and a clean path to hybrid cloud coordination.

---

## Supported Edge Platforms

| Platform | Architecture | Minimum RAM | Recommended starting model |
|---|---|---|---|
| Raspberry Pi 4/5 | ARM64 | 4 GB | Phi-3 Mini (Q4) |
| NVIDIA Jetson Orin Nano | ARM64 | 8 GB | Mistral 7B (Q4) |
| Generic x86_64 host | x86_64 | 4 GB | Phi-3 Mini (Q4) |
| GPU-backed x86_64 host | x86_64 | 16 GB | 7B to 8B GGUF |

---

## Install The Runtime

### 1. Download the archive

```bash
export IGRIS_PLATFORM="linux-arm64"

curl -fL "https://overture.igrisinertial.com/v1/runtime/install?platform=${IGRIS_PLATFORM}" \
  -o /tmp/igris-runtime.tar.gz

curl -fL "https://overture.igrisinertial.com/v1/runtime/checksum?platform=${IGRIS_PLATFORM}"
```

Verify the checksum output before extracting.

### 2. Extract and install

```bash
tar -xzf /tmp/igris-runtime.tar.gz -C /tmp
mkdir -p "$HOME/.local/bin"
mv /tmp/igris-runtime "$HOME/.local/bin/igris-runtime"
chmod +x "$HOME/.local/bin/igris-runtime"
export PATH="$HOME/.local/bin:$PATH"
```

### 3. Download a model

```bash
mkdir -p /opt/igris/models
wget -O /opt/igris/models/phi-3-mini-q4.gguf \
  "https://huggingface.co/microsoft/Phi-3-mini-4k-instruct-gguf/resolve/main/Phi-3-mini-4k-instruct-q4.gguf"
```

### 4. Configure the runtime

Create `/etc/igris/config.json5`:

```json5
{
  server: {
    host: "0.0.0.0",
    port: 8080
  },
  auth: {
    enabled: true,
    api_key: "YOUR_IGRIS_API_KEY"
  },
  local_fallback: {
    enabled: true,
    model_path: "/opt/igris/models/phi-3-mini-q4.gguf",
    n_gpu_layers: 0,
    threads: 4,
    context_size: 4096
  }
}
```

Platform tuning:

- **Raspberry Pi**: keep `n_gpu_layers` at `0`; tune `threads` to the available CPU cores
- **Jetson**: raise `n_gpu_layers` for GPU offload and keep `threads` conservative
- **GPU-backed x86_64**: increase `n_gpu_layers` based on VRAM capacity

### 5. Start the runtime

```bash
igris-runtime serve
```

If you want the device to appear in Fleet, also set `IGRIS_LICENSE_KEY` and `IGRIS_API_KEY` before startup.

## Run As A Service

Example `systemd` unit:

```ini
[Unit]
Description=Igris Runtime
After=network.target

[Service]
Type=simple
ExecStart=/home/igris/.local/bin/igris-runtime serve
Restart=on-failure
RestartSec=5
User=igris
Group=igris

[Install]
WantedBy=multi-user.target
```
