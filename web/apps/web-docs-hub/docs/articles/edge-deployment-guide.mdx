# Deploying Igris on Edge Devices

Running Igris on edge hardware enables offline inference, data residency, and low-latency responses. This guide covers deployment on the most common edge platforms.

---

## Supported Edge Platforms

| Platform | Architecture | Minimum RAM | Recommended Model |
|---|---|---|---|
| Raspberry Pi 4/5 | ARM64 | 4 GB | Phi-3 Mini (Q4) |
| Raspberry Pi 4/5 | ARM64 | 8 GB | Mistral 7B (Q4) |
| NVIDIA Jetson Orin Nano | ARM64 | 8 GB | Mistral 7B (Q4) |
| NVIDIA Jetson Orin NX | ARM64 | 16 GB | Llama 3 8B (Q4) |
| Generic x86_64 Server | x86_64 | 4 GB | Phi-3 Mini (Q4) |
| Generic x86_64 Server | x86_64 | 16 GB | Llama 3 8B (Q4) |

## Installation

### Step 1: Install the Runtime

```bash
curl -fsSL https://igrisinertial.com/install | bash
```

The installer detects your platform and downloads the correct binary.

### Step 2: Verify Installation

```bash
igris-runtime --version
# → igris-runtime v1.8.0 (linux/arm64)
```

### Step 3: Download a Model

For Raspberry Pi or Jetson devices, start with a quantized model:

```bash
# Download Phi-3 Mini (2.3 GB, Q4 quantized)
mkdir -p /opt/igris/models
wget -O /opt/igris/models/phi-3-mini-q4.gguf \
  "https://huggingface.co/microsoft/Phi-3-mini-4k-instruct-gguf/resolve/main/Phi-3-mini-4k-instruct-q4.gguf"
```

### Step 4: Configure the Runtime

Create `/etc/igris/config.json5`:

```json5
{
  server: {
    host: "0.0.0.0",
    port: 8080
  },
  auth: {
    enabled: true,
    api_key: "your-igris-api-key"
  },
  local_fallback: {
    enabled: true,
    model_path: "/opt/igris/models/phi-3-mini-q4.gguf",
    n_gpu_layers: 0,
    threads: 4,
    context_size: 4096
  },
  safety: {
    mode: "normal",
    enable_watchdog: true,
    watchdog_timeout_secs: 30
  }
}
```

**Platform-specific notes:**

- **Raspberry Pi**: Set `threads` to 4 (Pi 4) or 6 (Pi 5). Set `n_gpu_layers` to 0 (no GPU).
- **Jetson Orin**: Set `n_gpu_layers` to 35 for GPU offloading. Set `threads` to 4.
- **x86_64 with NVIDIA GPU**: Set `n_gpu_layers` to match your VRAM (typically 35–50 for 7B models).

### Step 5: Start the Runtime

```bash
igris-runtime serve --config /etc/igris/config.json5
```

### Step 6: Register with Fleet (Optional)

If you want cloud coordination, the runtime registers automatically on startup using your API key. Verify registration in **Fleet → Devices** in the console.

## Running as a Service

### systemd (Recommended for Production)

Create `/etc/systemd/system/igris-runtime.service`:

```ini
[Unit]
Description=Igris Runtime
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/igris-runtime serve --config /etc/igris/config.json5
Restart=on-failure
RestartSec=5
User=igris
Group=igris

[Install]
WantedBy=multi-user.target
```

Enable and start:

```bash
sudo systemctl daemon-reload
sudo systemctl enable igris-runtime
sudo systemctl start igris-runtime
```

## Performance Tuning

### Memory Optimization

Edge devices have limited RAM. Optimize with:

- **Use Q4 quantized models** — 4x smaller than full precision with minimal quality loss
- **Reduce context size** — Set `context_size` to 2048 instead of 4096 if your prompts are short
- **Limit concurrent requests** — Set `max_concurrent_requests` to 1–2 on devices with 4 GB RAM

### GPU Offloading (Jetson)

On Jetson devices with CUDA support:

```json5
{
  local_fallback: {
    n_gpu_layers: 35,
    main_gpu: 0
  }
}
```

This offloads 35 of the model's layers to the GPU, significantly improving inference speed.

### Thermal Management

Edge devices can throttle under sustained load. Monitor temperature:

```bash
# Raspberry Pi
vcgencmd measure_temp

# Jetson
cat /sys/devices/virtual/thermal/thermal_zone0/temp
```

If temperature exceeds 80°C, consider:
- Adding a heatsink or fan
- Reducing `threads` to lower CPU usage
- Adding cooldown periods between batch operations

## Troubleshooting

| Problem | Solution |
|---|---|
| Model fails to load | Check that the model file exists and is a valid GGUF format. Verify sufficient free RAM. |
| Inference is very slow | Use a smaller or more quantized model. Reduce context size. |
| Runtime crashes under load | Reduce `max_concurrent_requests`. Add swap space if available. |
| Device not appearing in Fleet | Verify outbound HTTPS access to `overture.igrisinertial.com`. Check API key. |
