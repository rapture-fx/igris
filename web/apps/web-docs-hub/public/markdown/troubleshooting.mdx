# Troubleshooting

## Authentication failures

**Symptoms:** `AuthenticationError`, HTTP 401.

**Checks:**

- `IGRIS_API_URL` is exactly the invitation endpoint (no trailing path beyond the host/base)
- `IGRIS_API_KEY` is the full `igris_…` secret
- The key was not truncated by shell history / secret managers
- You are not logging or rewriting the Authorization header

## Durable client configuration errors

**Symptoms:** `DurableConfigurationError` on construction or `from_env()`.

**Checks:**

- Both endpoint and API key are set
- You constructed `IgrisDurableClient` explicitly (env alone does not remote Embedded tools)

## Unbound Action

**Symptoms:** `UnboundActionError` on `run()`.

**Fix:** Create an exact binding with `contract_hash` and `target_action_id` first. See [Bind an Action](/docs/sdk-bind-action).

## Binding conflicts

**Symptoms:** `BindingConflictError`.

**Meaning:** This exact `contract_hash` is already immutably bound to a different target. Use the existing binding target, or create a new contract version.

## Missing / conflicting idempotency key

**Symptoms:** `DurableConfigurationError` (missing key) or `IdempotencyConflictError`.

**Fix:** Pass a stable business key. If conflict, inspect the existing run for that key instead of inventing a new one for the same business intent.

## Runtime unavailable

**Symptoms:** HTTP 503 / runtime unavailable errors on run submit.

**Fix:** Confirm Runtime is registered and healthy for the tenant. See [Runtime deployment](/docs/runtime-deployment).

## Wait timeout while recovering

**Symptoms:** `DurableTimeoutError` while status is still non-terminal / recovering.

**Fix:** Increase timeout and keep waiting. `recovering` is not terminal. Do not invent a manual resume step.

## Reconciliation required

**Symptoms:** `ReconciliationRequiredError`.

**Fix:** Do not auto-retry. Follow [Uncertain Effects](/docs/uncertain-effects) and [Reconciliation](/docs/reconciliation).

## Proof unavailable

**Symptoms:** `ProofUnavailableError`.

**Meaning:** Igris Run Proof is returned for contract-bound durable runs. Unbound or non-bound runs do not carry `igris_run_proof.v1`.
