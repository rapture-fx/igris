# Changelog

## External Alpha docs candidate

- Repositioned public docs around durable consequential Actions: Action → Run → Recover → Reconcile when uncertain → Prove
- First-contact path is now Quickstart → Your First Durable Action → Python `IgrisDurableClient`
- Install guidance uses distribution name `igris-sdk` (`import igris`); public `pip install igris` is explicitly rejected
- Claim boundaries for Igris Run Proof, Evidence, Runtime receipts, and operator reconciliation are documented literally
- Historical robotics, fleet, speculative execution, multimodal, and inference-first pages are removed from first-contact navigation
