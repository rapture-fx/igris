# Quickstart

This is the shortest path to one durable Action run with Igris.

You will install the Python SDK (`igris-sdk`), configure an endpoint and API key, bind one Action to an executable target, submit a run with a business idempotency key, wait for completion, and inspect **Igris Run Proof**.

## External Alpha access

External Alpha is invitation-gated. Igris provides:

- the API endpoint for your tenant
- a tenant-scoped API key (`igris_…`)

There is no public self-serve bootstrap that creates the first key without that invitation. If your invitation includes console access, you can rotate or create additional keys there later. Do not paste raw API keys into tickets, chat, screenshots, or logs.

Canonical hosted API hostname:

```text
https://overture.igrisinertial.com
```

Your invitation may point at a staging endpoint instead. Use exactly the endpoint you were given.

## 1. Install the SDK

Distribution name is **`igris-sdk`**. Import package is **`igris`**.

Do **not** run `pip install igris` from the public package index — that name is an unrelated third-party package.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -U pip

# From a repository or External Alpha kit checkout:
python -m pip install ./sdk/python

# Or install a supplied wheel (name may vary by kit):
# python -m pip install ./igris_sdk-0.1.0a2-py3-none-any.whl
```

Verify:

```bash
python -c "import igris; print(igris.__version__)"
igris --version
```

## 2. Configure endpoint and API key

```bash
export IGRIS_API_URL="https://overture.igrisinertial.com"   # or the endpoint from your invitation
export IGRIS_API_KEY="igris_…"                              # never commit or log this value
```

Construct the durable client explicitly:

```python
from igris import IgrisDurableClient

client = IgrisDurableClient(
    endpoint="https://overture.igrisinertial.com",
    api_key="igris_…",
)

# Or, after BOTH env vars are set:
# client = IgrisDurableClient.from_env()
```

Environment variables alone never switch local Embedded `wrap_tool` into remote execution. Durable mode requires `IgrisDurableClient`.

## 3. Run the first durable Action

Follow [Your First Durable Action](/docs/first-durable-action) for the complete sequence:

1. Declare / wrap the consequential function (local Embedded gate)
2. Synchronize the ActionContract
3. Create an Action target (webhook adapter)
4. Bind exact `contract_hash` → `target_action_id`
5. `client.run(..., idempotency_key=..., contract_hash=...)`
6. `run.wait()`
7. `run.proof()`

## What this quickstart does not do

- No raw control-plane curl in the normal SDK journey
- No manual checkpoint resume
- No uploading Python source to Runtime
- No invented random idempotency keys
- No claim of universal exactly-once external effects
