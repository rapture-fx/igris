# Deploy Local Runtime

Use this workflow when execution should happen on the machine itself instead of only through the hosted API.

Choose this path when you need:

- on-device inference
- local policy enforcement
- offline or low-connectivity operation
- runtime-local behavior tree execution

If those requirements are not central to the workload, start with the hosted API first. Local runtime is a deployment choice, not the default onboarding path.

---

## 1. Download the runtime archive

Use the runtime distribution endpoints for your platform and treat download as a provisioning step, not as application traffic.

```bash
export IGRIS_PLATFORM="linux-amd64"

curl -fL "https://overture.igrisinertial.com/v1/runtime/install?platform=${IGRIS_PLATFORM}" \
  -o /tmp/igris-runtime.tar.gz

curl -fL "https://overture.igrisinertial.com/v1/runtime/checksum?platform=${IGRIS_PLATFORM}"
```

Verify the archive checksum before installation.

## 2. Install the binary

```bash
tar -xzf /tmp/igris-runtime.tar.gz -C /tmp
mkdir -p "$HOME/.local/bin"
mv /tmp/igris-runtime "$HOME/.local/bin/igris-runtime"
chmod +x "$HOME/.local/bin/igris-runtime"
export PATH="$HOME/.local/bin:$PATH"
```

## 3. Configure auth and local model behavior

Create `~/.config/igris/config.json5`:

```json5
{
  server: {
    host: "0.0.0.0",
    port: 8080
  },
  auth: {
    enabled: true,
    api_key: "YOUR_IGRIS_API_KEY"
  },
  local_fallback: {
    enabled: true,
    model_path: "/models/phi-3-mini-4k-instruct-q4.gguf",
    context_size: 4096,
    threads: 4,
    n_gpu_layers: 0
  }
}
```

## 4. Start and verify the runtime

```bash
igris-runtime serve
curl http://localhost:8080/v1/health
```

Use the local runtime API only against the runtime base URL, not the hosted API. That sounds obvious, but it is one of the most common integration mistakes once teams begin mixing hosted and local deployment models.

## 5. Test a local call

```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'http://localhost:8080/v1',
  apiKey: process.env.IGRIS_API_KEY,
});

const response = await client.chat.completions.create({
  model: 'phi3',
  messages: [{ role: 'user', content: 'Hello from local runtime' }],
});
```

## Common Mistakes

- Pointing the client at `https://overture.igrisinertial.com` for a local-only route
- Assuming local auth behaves exactly like the hosted API
- Treating runtime download as a hot-path request rather than a provisioning step
