# ROS2 Integration (Technical Preview)

ROS2 integration is a **technical preview** surface.

Use this page when you need to understand how ROS2-related execution could fit under the Igris model. Do not treat it as a claim of broadly proven ROS2 production readiness.

Check [Proof Status](/docs/proof-status) before presenting ROS2 behavior beyond preview language.

---

## How It Fits

ROS2 integration is a specialized extension of the same execution model:

- requests still enter through Igris workflows
- execution still runs under boundaries and permissions
- verification still depends on execution events and signed records

The difference is simply that the surrounding environment is ROS2-oriented.

## What Teams Should Expect

Teams exploring this surface should expect:

- extra environment-specific integration work
- the need for explicit operator validation
- preview-level maturity rather than first-contact onboarding readiness

## Use It Carefully

This page is appropriate for specialized engineering evaluation.

It is not the right page to lead with when explaining the product to a new team, and it should not be used to imply broadly proven robotics or ROS2 deployment workflows.
