# GET /api/v1/runtime/download

Downloads or redirects to the runtime archive through the API-key authenticated runtime lifecycle surface. This is the endpoint custom installers use when they operate with a tenant API key rather than a browser session.

## When To Use

Use this endpoint from provisioning scripts, fleet bootstrap tooling, or custom installers that already hold a tenant API key. Use `/v1/runtime/download` when the download is initiated from a session-authenticated hosted workflow.

## Integration Guidance

Treat this as a provisioning operation. Retry 429 and transient 5xx responses with backoff, but do not call it repeatedly from the application hot path.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Treating a hybrid coordination route like a local-only runtime call without the required tenant context or fleet state.

## Query Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `platform` | `string` | No | Runtime archive platform. Supported values include `linux-amd64`, `linux-arm64`, `linux-armv7`, `macos-arm64`, and `macos-x64`. |

```bash
curl -X GET https://overture.igrisinertial.com/api/v1/runtime/download?platform=linux-amd64 \

```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Archive download | The runtime archive is streamed from local binary storage. |
| 302 | Redirect | The runtime archive is hosted externally and the response redirects to it. |
| 400 | Unsupported platform | The requested platform is not available. |
| 401 | Unauthorized | The tenant API key is missing or invalid. |
| 503 | Not configured | Runtime binary hosting is not configured on this server. |
