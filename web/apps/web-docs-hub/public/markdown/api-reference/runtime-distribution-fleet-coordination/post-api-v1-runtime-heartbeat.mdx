## When To Use

Use this endpoint when the workflow spans both the hosted control plane and one or more runtimes. It belongs to the Runtime Distribution & Fleet Coordination area of the product and is most useful when you are coordinating runtime distribution, fleet state, or device operations.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Treating a hybrid coordination route like a local-only runtime call without the required tenant context or fleet state.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `machine_id` | `string` | Yes | Stable runtime fingerprint for the host. |
| `bt_state` | `object` | No | Optional current behavior-tree state snapshot. |

## Request Example

```json
{
  "machine_id": "dev_0f4c3f1a2d9b45cf",
  "bt_state": {
    "tick": 418,
    "status": "running"
  }
}
```

### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"machine_id\": \"dev_0f4c3f1a2d9b45cf\",\n  \"bt_state\": {\n    \"tick\": 418,\n    \"status\": \"running\"\n  }\n}")

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/api/v1/runtime/heartbeat", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("X-API-Key", os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```
