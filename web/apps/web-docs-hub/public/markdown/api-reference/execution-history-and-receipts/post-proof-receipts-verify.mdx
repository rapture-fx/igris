# POST /proof/receipts/verify

Verifies a receipt hash and signature for a known execution. Use this to confirm the proof chain before presenting a receipt externally.

## When To Use

Use this endpoint when you need verifies a receipt signature and chain integrity. from the hosted API. It is part of the Execution, History, and Receipts surface and is intended to be the customer-facing contract for that capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Calling the route with an API key when the workflow actually expects an authenticated browser session.
- Using the wrong credential type or forgetting to send the expected API key header.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `execution_id` | `string` | Yes | Execution identifier to verify. |
| `expected_hash` | `string` | No | Optional expected receipt hash for direct comparison. |

## Request Example

```json
{
  "execution_id": "exec_01HV95R5Y3TVVJ7R3",
  "expected_hash": "6f16f4bc4d6627240ca4c7d66ea2d7d2"
}
```

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/proof/receipts/verify \
  -H "Authorization: Bearer $IGRIS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "execution_id": "exec_01HV95R5Y3TVVJ7R3",
  "expected_hash": "6f16f4bc4d6627240ca4c7d66ea2d7d2"
}'
```

### JavaScript


### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"execution_id\": \"exec_01HV95R5Y3TVVJ7R3\",\n  \"expected_hash\": \"6f16f4bc4d6627240ca4c7d66ea2d7d2\"\n}")

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/proof/receipts/verify", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```
