# GET /v1/history/events

Returns recent execution history for the tenant in a timeline-friendly format. Use it to understand what happened across agents and runtimes before you move into receipt-level proof review.

## When To Use

Use this endpoint for dashboards, operational investigations, and recent-activity views. It is the right first stop when you need a timeline, not a cryptographic artifact.

## Integration Guidance

Safe to retry on transient 5xx or 429 responses. Adjust your time window or filters if the dataset is larger than you expected rather than hammering the same request repeatedly.

### Common Mistakes

- Treating history events as the signed audit artifact instead of as an operational timeline.
- Pulling an unnecessarily large range without filters when you already know the agent or runtime you want to inspect.

## Query Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `range` | `string` | No | Time window such as `last_1h`, `last_24h`, or `last_7d`. |
| `limit` | `integer` | No | Maximum number of events to return. |
| `agent_id` | `string` | No | Optional agent filter. |
| `device_id` | `string` | No | Optional runtime/device filter. |

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/history/events?range=last_24h&limit=50 \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/history/events?range=last_24h&limit=50', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/history/events?range=last_24h&limit=50", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/history/events?range=last_24h&limit=50")

        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
