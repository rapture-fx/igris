# POST /v1/account/api-key

Creates a new tenant API key and returns the raw secret exactly once. The previous key is revoked when the new key is issued, so treat this route as a credential-rotation operation rather than a harmless read/write call.

## When To Use

Use this endpoint when you are creating the first tenant API key or intentionally rotating the current one. Plan the rollout so dependent systems can adopt the new credential immediately.

## Integration Guidance

Do not automatically replay this request. If the response is ambiguous, verify the current key state before attempting another rotation.

### Common Mistakes

- Calling the route without a rollout plan and breaking existing integrations when the old key is revoked.
- Assuming the raw secret can be recovered later if it is not stored at creation time.
- Using this route as part of routine request flow instead of as a deliberate credential-management action.

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/v1/account/api-key \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/account/api-key', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/v1/account/api-key", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::POST, "https://overture.igrisinertial.com/v1/account/api-key")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```

## Status Codes

| Code | Title | Description |
|---|---|---|
| 201 | Created | A new tenant API key was created and returned one time. |
| 401 | Unauthorized | Session or API key auth failed. |
| 500 | Generation failed | The platform could not generate or persist the new key. |
