## When To Use

This endpoint is experimental and disabled by default. It requires an explicit experimental feature flag on the deployment, is not part of the stable API contract, and may change or be removed. Do not build production integrations against it without confirming it is enabled and supported for your deployment.

## Integration Guidance

Retry only on clearly transient 5xx or 429 responses, and prefer idempotent client behavior. For preview routes, avoid aggressive automatic replay until you have validated the behavior in your environment.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `enabled` | `boolean` | No | Whether shadow routing should run for selected traffic. |
| `shadow_traffic_percent` | `number` | No | Percent of eligible traffic to shadow. |

## Request Example

```json
{
  "enabled": true,
  "shadow_traffic_percent": 10
}
```

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/v1/routing/shadow \
  -H "Authorization: Bearer $IGRIS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "enabled": true,
  "shadow_traffic_percent": 10
}'
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/routing/shadow', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
  "enabled": true,
  "shadow_traffic_percent": 10
}),
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"enabled\": true,\n  \"shadow_traffic_percent\": 10\n}")

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/v1/routing/shadow", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

