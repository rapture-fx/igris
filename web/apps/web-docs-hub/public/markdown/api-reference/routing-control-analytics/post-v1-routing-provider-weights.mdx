## When To Use

Use this endpoint when the operation belongs to the Routing Control & Analytics surface on the hosted API. It is intended to be the customer-facing contract for this capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `weights` | `object` | No | Provider weights keyed by provider identifier. |

## Request Example

```json
{
  "weights": {
    "openai": 0.7,
    "anthropic": 0.3
  }
}
```

## Code Examples

### cURL

```bash
curl -X POST https://overture.igrisinertial.com/v1/routing/provider_weights \
  -H "Authorization: Bearer $IGRIS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "weights": {
    "openai": 0.7,
    "anthropic": 0.3
  }
}'
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/routing/provider_weights', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
  "weights": {
    "openai": 0.7,
    "anthropic": 0.3
  }
}),
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := strings.NewReader("{\n  \"weights\": {\n    \"openai\": 0.7,\n    \"anthropic\": 0.3\n  }\n}")

req, err := http.NewRequest("POST", "https://overture.igrisinertial.com/v1/routing/provider_weights", body)
if err != nil {
	log.Fatal(err)
}
req.Header.Set("Content-Type", "application/json")
req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust
