# POST /v1/tasks/:id/proof/verify

Synchronizes persisted proof state for a durable task and returns the current verification view. The task must already have a persisted proof reference.

## When To Use

Use this endpoint when the operation belongs to the Durable Tasks surface on the hosted API. It is intended to be the customer-facing contract for this capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Success | Proof state was synchronized and returned. |
| 400 | Proof unavailable | The task has no persisted proof reference yet. |
| 404 | Not found | No task with this ID exists for the authenticated tenant. |
