# GET /v1/tasks/:id/steps

Returns the execution-graph steps and slot metadata that the coordinator can expose for a durable task. The response is empty for task types that do not produce step-level graph state.

## When To Use

Use this endpoint when the operation belongs to the Durable Tasks surface on the hosted API. It is intended to be the customer-facing contract for this capability.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.

## Path Parameters

| Field | Type | Required | Description |
|---|---|---|---|

## Status Codes

| Code | Title | Description |
|---|---|---|
| 200 | Success | Step list returned. The list may be empty. |
| 400 | Bad request | Task ID is not a valid UUID. |
| 404 | Not found | No task with this ID exists for the authenticated tenant. |
