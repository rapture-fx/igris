# GET /v1/tasks

Lists recent durable tasks for the authenticated tenant, newest first. Use it to build operational views of long-running work rather than polling every task individually from scratch.

## When To Use

Use this endpoint for dashboards, recent-work views, and operator workflows that need to see multiple durable tasks at once.

## Integration Guidance

Safe to retry on transient 5xx or 429 responses. Keep the query narrow and the refresh interval reasonable if the list is backing an active dashboard.

### Common Mistakes

- Using the list route when the client already has a single task ID and should call the detail route instead.
- Refreshing the task list too aggressively for long-running workloads that do not change every second.

## Query Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `limit` | `integer` | No | Maximum number of tasks to return. Defaults to 20, maximum 100. |

## Code Examples

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/tasks?limit=20 \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/tasks?limit=20', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/tasks?limit=20", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/tasks?limit=20")
        .header("Authorization", format!("Bearer {}", std::env::var("IGRIS_API_KEY")?))
        .send()
        .await?;

let payload = response.text().await?;
println!("{}", payload);
```
