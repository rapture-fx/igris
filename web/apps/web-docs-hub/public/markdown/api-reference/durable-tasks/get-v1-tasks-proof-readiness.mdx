# GET /v1/tasks/proof/readiness

Reports whether trigger-backed task proof synchronization is active. Use this before relying on immediate proof freshness for newly completed durable tasks.

## When To Use

Use this endpoint when the operation belongs to the Durable Tasks surface on the hosted API. It is intended to be the customer-facing contract for this capability.

## Integration Guidance

Safe retries are usually reasonable for transient 5xx or 429 responses. Do not retry 4xx responses until you have fixed the request, credentials, or addressed resource.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.

### cURL

```bash
curl -X GET https://overture.igrisinertial.com/v1/tasks/proof/readiness \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript

  },

const data = await response.text();
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("GET", "https://overture.igrisinertial.com/v1/tasks/proof/readiness", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::GET, "https://overture.igrisinertial.com/v1/tasks/proof/readiness")
```
