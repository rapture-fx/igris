## When To Use

Use this endpoint when the operation belongs to the Vault, Policy, and Governance surface on the hosted API. It is intended to be the customer-facing contract for this capability.

## Integration Guidance

Do not blindly retry write operations. Retry only on transient 5xx or 429 responses, and make sure the client is idempotent or otherwise safe to replay.

### Common Mistakes

- Using the wrong credential type or forgetting to send the expected API key header.
- Passing a placeholder path segment without replacing it with a real resource identifier.
- Replaying a write request without thinking through idempotency, duplication, or partial success.

## Code Examples

### cURL

```bash
curl -X DELETE https://overture.igrisinertial.com/v1/vault/keys/openai \
  -H "Authorization: Bearer $IGRIS_API_KEY"
```

### JavaScript

```javascript
const response = await fetch('https://overture.igrisinertial.com/v1/vault/keys/openai', {
  method: 'DELETE',
  headers: {
    'Authorization': `Bearer ${process.env.IGRIS_API_KEY}`,
  },
});

const data = await response.text();
console.log(data);
```

### Go

```go
client := &http.Client{}
body := http.NoBody

req, err := http.NewRequest("DELETE", "https://overture.igrisinertial.com/v1/vault/keys/openai", body)
if err != nil {
	log.Fatal(err)
}

req.Header.Set("Authorization", "Bearer " + os.Getenv("IGRIS_API_KEY"))

resp, err := client.Do(req)
if err != nil {
	log.Fatal(err)
}
defer resp.Body.Close()

payload, _ := io.ReadAll(resp.Body)
fmt.Println(string(payload))
```

### Rust

```rust
let client = reqwest::Client::new();
let response = client
        .request(reqwest::Method::DELETE, "https://overture.igrisinertial.com/v1/vault/keys/openai")

        .send()
        .await?;

```
