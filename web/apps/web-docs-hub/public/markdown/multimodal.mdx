# Multimodal Inference (Technical Preview)

Multimodal inference is a **technical preview** surface.

Use this page when you need to understand how multimodal execution could fit into Igris. Do not treat it as a broadly proven or customer-ready default path.

Check [Proof Status](/docs/proof-status) before promoting multimodal behavior beyond preview language.

---

## How It Fits

Multimodal work still belongs under the same Request -> Execute -> Verify model:

- **Request** includes text plus one or more additional modalities
- **Execute** depends on the configured multimodal-capable path
- **Verify** depends on the execution record that comes back from that run

The preview status is about maturity, not about a different product identity.

## What To Expect

This surface is appropriate for evaluation when teams want to explore:

- text-plus-image workflows
- text-plus-audio workflows
- how multimodal requests should be represented in execution and verification workflows

Use careful language:

- multimodal support should be treated as preview-oriented
- provider-backed proof should be checked before making stronger readiness claims
- stub-heavy or partial behavior should be assumed possible until validated in the target environment
