# Python SDK

The External Alpha product path is the Python durable SDK.

- **Distribution name:** `igris-sdk`
- **Import package:** `igris`
- **Durable client:** `IgrisDurableClient`

Do **not** `pip install igris` from the public package index.

## Install

```bash
python -m pip install ./sdk/python
# or a kit wheel: python -m pip install ./igris_sdk-0.1.0a2-py3-none-any.whl
```

```python
import igris
from igris import IgrisDurableClient
```

## Embedded vs durable

| Mode | Entry point | Network by default? |
|---|---|---|
| Embedded | `igris.wrap_tool` / `@igris.guard` | No — local journal and approval |
| Durable | `IgrisDurableClient` | Yes — explicit endpoint + API key |

Setting `IGRIS_API_URL` alone never remotes Embedded tools. Construct `IgrisDurableClient` when you want managed durable execution.
