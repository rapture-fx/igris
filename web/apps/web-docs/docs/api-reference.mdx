# API Reference

Complete REST API reference for Schlep Engine. All endpoints are OpenAI-compatible with additional enterprise features.

## Base URL

```
Production:  https://api.schlep-engine.com
Staging:     https://api-staging.schlep-engine.com
Local:       http://localhost:8080
```

## Authentication

All API requests require authentication via **API Key** or **JWT token**.

### API Key Authentication

```bash
curl https://api.schlep-engine.com/v1/infer \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

### JWT Authentication

```bash
# Login to get token
curl -X POST https://api.schlep-engine.com/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "password"
  }'

# Use token in subsequent requests
curl https://api.schlep-engine.com/v1/infer \
  -H "Authorization: Bearer JWT_TOKEN" \
  -H "Content-Type: application/json"
```

### Inference (OpenAI-Compatible)

Perform inference with automatic provider selection.

```bash
POST /v1/infer
POST /v1/chat/completions  # OpenAI-compatible alias
```

**Request:**
```json
{
  "model": "gpt-4",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant"},
    {"role": "user", "content": "Explain quantum computing"}
  ],
  "temperature": 0.7,
  "max_tokens": 1000,
  "stream": false,

  // Schlep Engine extensions
  "routing_policy": "thompson-sampling",
  "speculative_mode": "latency",
  "enable_semantic_routing": true,
  "optimization": "balanced"
}
```

**Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `model` | string | required | Model identifier (e.g., "gpt-4", "claude-3-sonnet") |
| `messages` | array | required | Array of message objects with role and content |
| `temperature` | float | 0.7 | Sampling temperature (0.0 - 2.0) |
| `max_tokens` | int | provider default | Maximum tokens to generate |
| `top_p` | float | 1.0 | Nucleus sampling parameter |
| `stream` | boolean | false | Enable streaming response |
| `routing_policy` | string | "thompson-sampling" | Routing strategy |
| `speculative_mode` | string | null | Speculative execution mode: "latency", "balanced", "quality", "cost" |
| `council_mode` | boolean | false | Enable council mode (Growth+) |
| `provider` | string | auto | Explicitly specify provider |
| `optimization` | string | "balanced" | Optimization goal: "latency", "cost", "quality", "balanced" |

**Response (Non-Streaming):**
```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1701234567,
  "model": "gpt-4",

      },

    }

    "prompt_tokens": 25,

  },

    "provider": "openai",
```

## Metrics & Monitoring

### Prometheus Metrics

All metrics are exposed at the `/metrics` endpoint in Prometheus format.

```bash
GET /metrics
```

**Key Metrics:**

**Request Metrics:**
```promql
# Total requests
http_requests_total{method="POST", path="/v1/infer", status="200"}

# Request duration
histogram_quantile(0.95, http_request_duration_seconds{method="POST"})

# Provider requests
inference_requests_total{provider="openai", model="gpt-4"}

# Provider latency
histogram_quantile(0.95, inference_latency_seconds{provider="openai"})
```

**Cost Metrics:**
```promql
# Total cost
cost_usd_total{provider="openai", component="inference"}

# Cost per request
rate(cost_usd_total[1h]) / rate(inference_requests_total[1h])

# Budget utilization
(tenant_cost_usd / tenant_budget_usd) * 100
```

**Routing Metrics:**
```promql
# Routing decisions
routing_decisions_total{policy="thompson-sampling"}

# Thompson Sampling scores
thompson_sampling_score{provider="openai"}

# Speculative execution savings
speculative_latency_saved_seconds{mode="latency"}

# Circuit breaker state
circuit_breaker_state{name="openai"}
```

## Error Responses

All errors follow a consistent format:

```json
{
  "error": {
    "type": "authentication_error",
    "code": "invalid_api_key",
    "message": "The API key provided is invalid",
    "request_id": "req_abc123",
    "documentation_url": "https://docs.schlep-engine.com/errors/invalid_api_key"
  }
}
```

**HTTP Status Codes:**

| Code | Meaning | Common Causes |
|------|---------|---------------|
| 200 | Success | Request completed successfully |
| 400 | Bad Request | Invalid parameters or malformed JSON |
| 401 | Unauthorized | Missing or invalid API key |
| 402 | Payment Required | Budget limit exceeded |
| 403 | Forbidden | Insufficient permissions or tier limits |
| 404 | Not Found | Resource does not exist |
| 429 | Too Many Requests | Rate limit exceeded |
| 500 | Internal Server Error | Server-side error |
| 502 | Bad Gateway | Provider API error |
| 503 | Service Unavailable | All providers unhealthy |

**Error Types:**

- `authentication_error`: API key invalid or expired
- `authorization_error`: Insufficient permissions
- `rate_limit_error`: Too many requests
- `budget_limit_error`: Monthly budget exceeded
- `validation_error`: Invalid request parameters
- `provider_error`: Provider API returned error
- `timeout_error`: Request timed out
- `circuit_breaker_error`: Provider circuit breaker open

## Rate Limits

Rate limits are tier-based and enforced per tenant:

| Tier | Requests/Second | Requests/Minute | Requests/Month |
|------|----------------|-----------------|----------------|
| Trial | 10 | 300 | 50,000 |
| Developer | 10 | 300 | 500,000 |
| Growth | 50 | 1,500 | 2,000,000 |
| Scale | 1,000 | 60,000 | Unlimited |

**Rate Limit Headers:**
```
X-RateLimit-Limit: 50
X-RateLimit-Remaining: 42
X-RateLimit-Reset: 1701234567
```

## Versioning

The API uses URL versioning. Current version is **v1**.

```
https://api.schlep-engine.com/v1/infer
```

When breaking changes are introduced, a new version (v2) will be released alongside v1.

## WebSocket API (Real-time Updates)

Connect to WebSocket for real-time streaming and updates.

```javascript
const ws = new WebSocket('wss://api.schlep-engine.com/v1/stream');

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Received:', data);
};

// Subscribe to job updates
ws.send(JSON.stringify({
  type: 'subscribe',
  channel: 'job',
  job_id: 'job_abc123'
}));
```
