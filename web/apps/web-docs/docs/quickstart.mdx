# Quick Start

**TL;DR:** Install the Igris runtime with one command, then point your OpenAI SDK to Igris for automatic routing, failover, and cost optimization.

---

## Install Igris Runtime

```bash
curl -fsSL https://igrisinertial.com/install | bash
```

The installer detects your platform (Linux x86-64, ARM64, macOS Apple Silicon, macOS Intel, Windows), downloads the correct binary, verifies the checksum, and installs to `/usr/local/bin/igris-runtime`.

### Authenticate

Once installed, authenticate with your API key:

```bash
igris-runtime auth igris_...
```

Then start the runtime:

```bash
igris-runtime serve
```

Get your API key from **Settings → Keys** in the [console](https://console.igrisinertial.com/settings/keys).

### Verify

Once running, the runtime registers itself with your fleet. It appears in **Fleet → Devices** within a minute.

> **Manual download:** If scripts are restricted in your environment, download the binary directly from your console at **Fleet → Downloads**.


Your API key looks like: `igris_abc123...`

### Step 3: Make Your First Request

**Using Python (OpenAI SDK):**

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://overture.igrisinertial.com/v1",
    api_key=os.environ['IGRIS_API_KEY']
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
print(f"Cost: ${response.metadata['cost_usd']:.4f}")
print(f"Provider: {response.metadata['provider']}")
```

**Using Node.js:**

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://overture.igrisinertial.com/v1',
  apiKey: process.env.IGRIS_API_KEY
});

const response = await client.chat.completions.create({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Hello!' }]
});

console.log(response.choices[0].message.content);
console.log(`Cost: $${response.metadata.cost_usd}`);
console.log(`Provider: ${response.metadata.provider}`);
```

**Using cURL:**

```bash
curl -X POST https://overture.igrisinertial.com/v1/infer \
  -H "Authorization: Bearer $IGRIS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4",
    "messages": [
      {"role": "user", "content": "Explain Thompson Sampling in one sentence"}
    ]
  }'
```

## What You Get in the Response

Every request includes metadata about routing:

```json
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "model": "gpt-4",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Thompson Sampling is a Bayesian algorithm that balances exploration and exploitation..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 28,
    "total_tokens": 40
  },
  "metadata": {
    "provider": "anthropic",              // Which provider handled the request
    "routing_decision": "thompson-sampling", // How the decision was made
    "cost_usd": 0.00034,                  // Actual cost in USD
    "latency_ms": 187,                    // Request latency
    "trace_id": "550e8400-e29b..."        // Distributed trace ID
  }
}
```

<summary><strong>Streaming Responses</strong></summary>

Get tokens as they're generated:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://overture.igrisinertial.com/v1",
    api_key="$IGRIS_API_KEY"
)

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end='', flush=True)
```
