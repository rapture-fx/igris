# Request Modes

The execution engine supports several inference modes beyond standard chat completion. Set the `mode` field in your request body to select a mode.

---

## Standard Mode (default)

No `mode` field required. The engine forwards the request to the selected provider and returns the response.

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "messages": [{"role": "user", "content": "What is 2+2?"}]
  }'
```

---

## Reflection Mode

The model generates a response, critiques it, and regenerates if quality is below threshold.

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "mode": "reflection",
    "reflection": {
      "quality_threshold": 0.7,
      "max_iterations": 3
    },
    "messages": [{"role": "user", "content": "Explain quantum entanglement."}]
  }'
```

**Parameters:**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `reflection.quality_threshold` | float | `0.7` | Score (0.0–1.0) below which the model regenerates |
| `reflection.max_iterations` | integer | `3` | Maximum regeneration attempts |

**Response includes:**

```json
{
  "choices": [...],
  "metadata": {
    "mode": "reflection",
    "iterations": 2,
    "final_quality_score": 0.84
  }
}
```

---

## Planning Mode

The model breaks down complex tasks with chain-of-thought: Plan → Act → Observe → Reflect.

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "mode": "planning",
    "messages": [{"role": "user", "content": "Write a Python script that reads a CSV and generates a bar chart."}]
  }'
```

**Response includes:**

```json
{
  "choices": [...],
  "metadata": {
    "mode": "planning",
    "plan_steps": 4,
    "execution_steps": 4
  }
}
```

---

## Tool Mode

The model can call registered tools (HTTP, shell, filesystem) to answer the request.

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "mode": "tools",
    "messages": [{"role": "user", "content": "What is the current Bitcoin price?"}]
  }'
```

Tools must be enabled and configured in `config.json5`. See [Tool Use →](/docs/core-features/tools).

---

## Swarm Mode

Multiple specialized agents collaborate on the request, with a synthesizer combining their outputs.

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "mode": "swarm",
    "swarm": {
      "agents": 4,
      "consensus": false
    },
    "messages": [{"role": "user", "content": "Analyze the trade-offs of microservices vs monolith."}]
  }'
```

**Parameters:**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `swarm.agents` | integer | `4` | Number of parallel agents |
| `swarm.consensus` | boolean | `false` | Require majority agreement before returning |

---

## Mode Summary

| Mode | Field | Best For |
|---|---|---|
| Standard | _(none)_ | Simple Q&A, code generation, general use |
| Reflection | `"reflection"` | High-quality answers, factual accuracy |
| Planning | `"planning"` | Multi-step tasks, complex reasoning |
| Tool | `"tools"` | Real-time data, external API calls |
| Swarm | `"swarm"` | Complex analysis, multiple perspectives |
