# GET /metrics

Exposes Prometheus-format metrics for the execution engine. Scrape this endpoint with Prometheus or any compatible collector.

---

## Request

```bash
curl http://localhost:8080/metrics
```

No authentication required by default. To restrict access, configure `metrics_auth` in your engine config.

---

## Response

The response is in Prometheus text exposition format:

```
# HELP igris_requests_total Total number of inference requests
# TYPE igris_requests_total counter
igris_requests_total{provider="openai",status="success"} 1423
igris_requests_total{provider="anthropic",status="success"} 287
igris_requests_total{provider="local",status="success"} 94
igris_requests_total{provider="openai",status="error"} 12

# HELP igris_request_duration_seconds Request latency histogram
# TYPE igris_request_duration_seconds histogram
igris_request_duration_seconds_bucket{provider="openai",le="0.1"} 34
igris_request_duration_seconds_bucket{provider="openai",le="0.5"} 891
igris_request_duration_seconds_bucket{provider="openai",le="1.0"} 1401
igris_request_duration_seconds_bucket{provider="openai",le="+Inf"} 1423
igris_request_duration_seconds_sum{provider="openai"} 512.4
igris_request_duration_seconds_count{provider="openai"} 1423

# HELP igris_tokens_total Total tokens consumed
# TYPE igris_tokens_total counter
igris_tokens_total{provider="openai",type="prompt"} 284600
igris_tokens_total{provider="openai",type="completion"} 89200

# HELP igris_local_model_loaded Whether the local GGUF model is loaded
# TYPE igris_local_model_loaded gauge
igris_local_model_loaded 1

# HELP igris_active_requests Current number of in-flight requests
# TYPE igris_active_requests gauge
igris_active_requests 3

# HELP igris_receipts_stored Total execution receipts stored locally
# TYPE igris_receipts_stored counter
igris_receipts_stored 1804

# HELP igris_capability_violations_total Policy violations blocked by the enforcement layer
# TYPE igris_capability_violations_total counter
igris_capability_violations_total{capability="tool_shell"} 2
igris_capability_violations_total{capability="tool_http"} 0
```

---

## Key Metrics

| Metric | Type | Description |
|---|---|---|
| `igris_requests_total` | Counter | Requests by provider and status (`success`/`error`/`timeout`) |
| `igris_request_duration_seconds` | Histogram | End-to-end request latency per provider |
| `igris_tokens_total` | Counter | Token consumption split by prompt/completion |
| `igris_local_model_loaded` | Gauge | `1` if local model is ready, `0` if not |
| `igris_active_requests` | Gauge | Number of requests currently being processed |
| `igris_receipts_stored` | Counter | Total signed execution receipts in local storage |
| `igris_capability_violations_total` | Counter | Blocked operations by capability type |

## Prometheus Scrape Config

```yaml
scrape_configs:
  - job_name: igris-runtime
    static_configs:
      - targets: ['localhost:8080']
    metrics_path: /metrics
    scrape_interval: 15s
```
