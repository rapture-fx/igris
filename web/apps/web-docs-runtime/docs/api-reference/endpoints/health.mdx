# GET /v1/health

Returns the current health status of the execution engine. Use this endpoint for liveness probes and uptime monitoring.

---

## Request

```bash
curl http://localhost:8080/v1/health \
  -H "Authorization: Bearer YOUR_API_KEY"
```

No request body. Authentication is optional if the engine is configured without API key enforcement.

---

## Response

```json
{
  "status": "ok",
  "version": "0.9.1",
  "uptime_seconds": 3821,
  "local_model": {
    "loaded": true,
    "path": "models/phi-3-mini-4k-instruct-q4.gguf",
    "context_size": 4096
  },
  "providers": {
    "openai": "reachable",
    "anthropic": "reachable",
    "google": "unreachable"
  }
}
```

### Fields

| Field | Type | Description |
|---|---|---|
| `status` | string | `"ok"` when the engine is healthy, `"degraded"` if any non-critical subsystem has failed |
| `version` | string | Engine binary version |
| `uptime_seconds` | integer | Seconds since the engine process started |
| `local_model.loaded` | boolean | Whether a local GGUF model is loaded and ready |
| `local_model.path` | string | Path to the loaded model file |
| `local_model.context_size` | integer | Context window size in tokens |
| `providers` | object | Reachability status for each configured cloud provider |

---

## Status Codes

| Code | Meaning |
|---|---|
| `200` | Engine is healthy or degraded but operational |
| `503` | Engine is not ready to serve requests |

---

## Use Cases

**Kubernetes liveness probe:**

```yaml
livenessProbe:
  httpGet:
    path: /v1/health
    port: 8080
  initialDelaySeconds: 10
  periodSeconds: 30
```

**Readiness probe:**

```yaml
readinessProbe:
  httpGet:
    path: /v1/health
    port: 8080
  initialDelaySeconds: 5
  periodSeconds: 10
```

**Shell health check:**

```bash
STATUS=$(curl -s http://localhost:8080/v1/health | jq -r '.status')
if [ "$STATUS" != "ok" ]; then
  echo "Engine unhealthy: $STATUS"
  exit 1
fi
```
