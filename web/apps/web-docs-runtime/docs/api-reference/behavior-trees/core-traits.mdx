# Core Traits API Reference

Complete API reference for core behavior tree traits and types.

---

## BTreeNode Trait

The base trait that all behavior tree nodes implement.

### Definition

```rust
#[async_trait]
pub trait BTreeNode: Send + Sync {
    fn name(&self) -> &str;
    fn node_type(&self) -> &str;
    async fn tick(&mut self, context: &mut BTreeContext) -> Result<NodeStatus>;
    async fn reset(&mut self);
    async fn halt(&mut self);
    fn to_json(&self) -> Result<serde_json::Value>;
    fn metadata(&self) -> NodeMetadata;
}
```

### Required Methods

#### name()

```rust
fn name(&self) -> &str
```

Returns the node's human-readable identifier.

**Example:**
```rust
let node = Sequence::new("mission_sequence");
assert_eq!(node.name(), "mission_sequence");
```

#### node_type()

```rust
fn node_type(&self) -> &str
```

Returns the node type for serialization and debugging.

**Returns:** One of: "Sequence", "Selector", "Parallel", "Retry", "Timeout", "Inverter", "Repeat", "SetBlackboard", "ToolAction", "CheckBlackboard", "LLMPlannerNode", "SubtreeLoader", "ReplanOnFailure", "Watchdog"

**Example:**
```rust
let node = Sequence::new("test");
assert_eq!(node.node_type(), "Sequence");
```

#### tick()

```rust
async fn tick(&mut self, context: &mut BTreeContext) -> Result<NodeStatus>
```

Executes one step of the node's logic.

**Parameters:**
- `context`: Mutable reference to execution context

**Returns:**
- `Ok(NodeStatus)`: The execution status
- `Err(anyhow::Error)`: Critical errors

**Example:**
```rust
let mut node = SetBlackboard::new("set", "key", "value");
let mut context = BTreeContext::new();

let status = node.tick(&mut context).await?;
assert_eq!(status, NodeStatus::Success);
```

### Optional Methods

#### reset()

```rust
async fn reset(&mut self)
```

Clears internal state. Default implementation is a no-op.

**Example:**
```rust
let mut node = Retry::new("retry", child, 3);
node.reset().await;
// Retry counter is now reset to 0
```

#### halt()

```rust
async fn halt(&mut self)
```

Emergency stop. Default implementation calls `reset()`.

**Example:**
```rust
let mut node = Timeout::new("timed", child, Duration::from_secs(5));
node.halt().await;
// Timer stopped, child halted
```

#### to_json()

```rust
fn to_json(&self) -> Result<serde_json::Value>
```

Serializes node to JSON.

**Example:**
```rust
let node = Sequence::new("test")
    .add_child(Box::new(SetBlackboard::new("a", "k", "v")));

let json = node.to_json()?;
assert_eq!(json["type"], "Sequence");
assert!(json["children"].is_array());
```

#### metadata()

```rust
fn metadata(&self) -> NodeMetadata
```

Returns node metadata for visualization.

**Example:**
```rust
let node = SetBlackboard::new("test", "key", "value");
let metadata = node.metadata();

assert_eq!(metadata.name, "test");
assert_eq!(metadata.node_type, "SetBlackboard");
```

## NodeStatus Enum

Represents the execution state of a node.

### Definition

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum NodeStatus {
    Running,   // Still executing
    Success,   // Completed successfully
    Failure,   // Failed
    Skipped,   // Skipped by parent
}
```

### Methods

#### is_terminal()

```rust
pub fn is_terminal(&self) -> bool
```

Returns `true` if status is Success, Failure, or Skipped.

**Example:**
```rust
assert!(!NodeStatus::Running.is_terminal());
assert!(NodeStatus::Success.is_terminal());
assert!(NodeStatus::Failure.is_terminal());
```

#### is_running()

```rust
pub fn is_running(&self) -> bool
```

Returns `true` if status is Running.

## BTreeContext

Execution context holding shared state.

### Definition

```rust
pub struct BTreeContext {
    pub blackboard: Blackboard,
    llm_provider: Option<Arc<dyn LlmProvider>>,
    rt_executor: Option<Arc<dyn Any>>,
    tool_registry: Option<Arc<dyn Any>>,
}
```

### Construction

#### new()

```rust
pub fn new() -> Self
```

Creates a new empty context.

**Example:**
```rust
let context = BTreeContext::new();
```

#### with_llm()

```rust
pub fn with_llm(mut self, provider: Arc<dyn LlmProvider>) -> Self
```

Attaches an LLM provider.

**Example:**
```rust
let llm = Arc::new(MockLlmProvider::new(responses));
let context = BTreeContext::new().with_llm(llm);
```

#### with_rt_executor()

```rust
pub fn with_rt_executor(mut self, executor: Arc<dyn Any>) -> Self
```

Attaches a real-time executor.

#### with_tool_registry()

```rust
pub fn with_tool_registry(mut self, registry: Arc<dyn Any>) -> Self
```

Attaches a tool registry.

### Methods

#### llm_provider()

```rust
pub fn llm_provider(&self) -> Option<Arc<dyn LlmProvider>>
```

Returns the LLM provider if set.

#### has_llm()

```rust
pub fn has_llm(&self) -> bool
```

Returns `true` if LLM provider is configured.

## Blackboard

Thread-safe key-value store for shared state.

### Definition

```rust
pub struct Blackboard {
    data: Arc<RwLock<HashMap<String, Value>>>,
}
```

### Construction

#### new()

```rust
pub fn new() -> Self
```

Creates a new empty blackboard.

### Methods

#### set()

```rust
pub async fn set<T: Serialize>(&self, key: impl Into<String>, value: T)
```

Sets a key-value pair.

**Example:**
```rust
blackboard.set("status", "running").await;
blackboard.set("count", 42).await;
blackboard.set("ready", true).await;
```

#### get()

```rust
pub async fn get<T: DeserializeOwned>(&self, key: &str) -> Result<T>
```

Retrieves a value by key.

**Returns:**
- `Ok(T)`: The value
- `Err`: Key not found or type mismatch

**Example:**
```rust
let status: String = blackboard.get("status").await?;
let count: i32 = blackboard.get("count").await?;
let ready: bool = blackboard.get("ready").await?;
```

#### contains()

```rust
pub async fn contains(&self, key: &str) -> bool
```

Checks if a key exists.

**Example:**
```rust
if blackboard.contains("status").await {
    let status: String = blackboard.get("status").await?;
}
```

#### remove()

```rust
pub async fn remove(&self, key: &str)
```

Removes a key-value pair.

**Example:**
```rust
blackboard.remove("temporary_data").await;
```

#### clear()

```rust
pub async fn clear(&self)
```

Removes all key-value pairs.

**Example:**
```rust
blackboard.clear().await;
```

#### keys()

```rust
pub async fn keys(&self) -> Vec<String>
```

Returns all keys.

**Example:**
```rust
let all_keys = blackboard.keys().await;
for key in all_keys {
    println!("Key: {}", key);
}
```

## NodeMetadata

Metadata structure for visualization and debugging.

### Definition

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct NodeMetadata {
    pub id: String,
    pub name: String,
    pub node_type: String,
    pub status: Option<String>,
    pub tick_count: u64,
    pub last_result: Option<String>,
}
```

### Fields

- **id**: Unique node identifier (e.g., "Sequence_mission")
- **name**: Human-readable name
- **node_type**: Type identifier (e.g., "Sequence", "LLMPlanner")
- **status**: Current execution status (if available)
- **tick_count**: Number of times ticked
- **last_result**: Last execution result or error message

## Usage Examples

### Complete Example

```rust
use igris_btree::prelude::*;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Create context
    let mut context = BTreeContext::new();

    // Set values in blackboard
    context.blackboard.set("mission", "Navigate to A3").await;
    context.blackboard.set("battery", 95).await;

    // Create node
    let mut node = Sequence::new("test_sequence")
        .add_child(Box::new(CheckBlackboard::new("check", "battery", 95)))
        .add_child(Box::new(SetBlackboard::new("act", "status", "running")));

    // Tick node
    let status = node.tick(&mut context).await?;
    println!("Status: {:?}", status);

    // Check metadata
    let metadata = node.metadata();
    println!("Node: {} ({})", metadata.name, metadata.node_type);

    // Verify blackboard
    let status: String = context.blackboard.get("status").await?;
    assert_eq!(status, "running");

    Ok(())
}
```

### Testing with Mocks

```rust
#[tokio::test]
async fn test_btree_node() {
    let mut context = BTreeContext::new();
    context.blackboard.set("test_key", "test_value").await;

    let mut node = SetBlackboard::new("test", "output", "result");
    let status = node.tick(&mut context).await.unwrap();

    assert_eq!(status, NodeStatus::Success);
    assert!(context.blackboard.contains("output").await);

    let output: String = context.blackboard.get("output").await.unwrap();
    assert_eq!(output, "result");
}
```

## Thread Safety

All core types are thread-safe:

- **BTreeNode**: `Send + Sync`
- **BTreeContext**: Internally synchronized
- **Blackboard**: `Arc<RwLock<>>` for concurrent access
- **NodeStatus**: `Copy` type, trivially thread-safe

## Error Handling

### Node Errors

Nodes return `Result<NodeStatus>`:

```rust
// Return status for normal cases
Ok(NodeStatus::Success)
Ok(NodeStatus::Failure)

// Return error for critical failures
Err(anyhow::anyhow!("Critical error"))
```

### Blackboard Errors

Blackboard operations return `Result<T>`:

```rust
// Get may fail
match blackboard.get::<String>("key").await {
    Ok(value) => println!("Value: {}", value),
    Err(e) => println!("Key not found: {}", e),
}
```

## Best Practices

1. **Name nodes clearly**: Use descriptive names for debugging
2. **Type safety**: Use typed get/set for blackboard
3. **Check existence**: Use `contains()` before `get()`
4. **Clean up**: Remove temporary blackboard keys
5. **Reset state**: Implement `reset()` for stateful nodes
6. **Graceful halt**: Implement `halt()` for async nodes
7. **Document metadata**: Provide meaningful metadata
