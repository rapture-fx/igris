# BTreeExecutor API Reference

Complete API reference for the behavior tree executor.

---

## BTreeExecutor

High-level executor with lifecycle management and execution bounds.

### Definition

```rust
pub struct BTreeExecutor {
    config: ExecutorConfig,
    visualizer: Option<Arc<TreeVisualizer>>,
}
```

## Execution Methods

### execute()

```rust
pub async fn execute(
    &self,
    tree: &mut dyn BTreeNode,
    context: &mut BTreeContext,
) -> Result<ExecutionResult>
```

Executes a behavior tree until completion or limits reached.

**Parameters:**
- `tree`: The root node to execute
- `context`: Execution context with blackboard and providers

**Returns:**
- `Ok(ExecutionResult)`: Execution completed
- `Err(anyhow::Error)`: Critical error during execution

**Example:**
```rust
let executor = BTreeExecutor::new()
    .with_max_ticks(100);

let mut tree = Sequence::new("mission");
let mut context = BTreeContext::new();

let result = executor.execute(&mut tree, &mut context).await?;

println!("Status: {:?}", result.status);
println!("Ticks: {}", result.tick_count);
```

### execute_with_cancel()

```rust
pub async fn execute_with_cancel(
    &self,
    tree: &mut dyn BTreeNode,
    context: &mut BTreeContext,
    cancel_rx: watch::Receiver<bool>,
) -> Result<ExecutionResult>
```

Executes with cancellation support.

**Parameters:**
- `tree`: The root node to execute
- `context`: Execution context
- `cancel_rx`: Cancellation channel receiver

**Returns:**
- `Ok(ExecutionResult)`: Execution completed or cancelled
- `Err(anyhow::Error)`: Critical error during execution

**Example:**
```rust
use tokio::sync::watch;

let executor = BTreeExecutor::new();
let (cancel_tx, cancel_rx) = watch::channel(false);

let handle = tokio::spawn(async move {
    executor.execute_with_cancel(&mut tree, &mut context, cancel_rx).await
});

// Later: cancel execution
cancel_tx.send(true)?;

let result = handle.await??;
println!("Cancelled: {}", result.cancelled);
```

## ExecutorConfig

Configuration for executor behavior.

### Definition

```rust
#[derive(Debug, Clone)]
pub struct ExecutorConfig {
    pub max_ticks: Option<u64>,
    pub deadline: Option<Duration>,
    pub enable_tracing: bool,
    pub tick_delay: Option<Duration>,
}
```

### Fields

- **max_ticks**: Maximum number of ticks (None = unlimited)
- **deadline**: Maximum execution duration (None = unlimited)
- **enable_tracing**: Enable debug logging
- **tick_delay**: Delay between ticks (None = no delay)

### Default

```rust
impl Default for ExecutorConfig {
    fn default() -> Self {
        Self {
            max_ticks: None,
            deadline: None,
            enable_tracing: false,
            tick_delay: None,
        }
    }
}
```

## ExecutionResult

Results and metadata from execution.

### Definition

```rust
pub struct ExecutionResult {
    pub status: NodeStatus,
    pub tick_count: u64,
    pub duration: Duration,
    pub cancelled: bool,
    pub max_ticks_reached: bool,
    pub deadline_exceeded: bool,
    pub errors: Vec<String>,
}
```

### Fields

- **status**: Final status of the tree
- **tick_count**: Total ticks executed
- **duration**: Total execution time
- **cancelled**: Whether execution was cancelled
- **max_ticks_reached**: Whether max ticks limit was hit
- **deadline_exceeded**: Whether deadline was exceeded
- **errors**: Any errors during execution

### Construction

#### new()

```rust
pub fn new(status: NodeStatus, tick_count: u64, duration: Duration) -> Self
```

Creates a new result.

#### with_cancelled()

```rust
pub fn with_cancelled(mut self) -> Self
```

Marks result as cancelled.

#### with_max_ticks()

```rust
pub fn with_max_ticks(mut self) -> Self
```

Marks max ticks reached.

#### with_deadline_exceeded()

```rust
pub fn with_deadline_exceeded(mut self) -> Self
```

Marks deadline exceeded.

#### add_error()

```rust
pub fn add_error(mut self, error: impl Into<String>) -> Self
```

Adds an error message.

### Display

```rust
impl Display for ExecutionResult {
    fn fmt(&self, f: &mut Formatter<'_>) -> fmt::Result {
        write!(
            f,
            "ExecutionResult {{ status: {:?}, ticks: {}, duration: {:?} }}",
            self.status, self.tick_count, self.duration
        )
    }
}
```

## Usage Examples

### Basic Execution

```rust
use igris_btree::prelude::*;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let executor = BTreeExecutor::new();

    let mut tree = Sequence::new("simple")
        .add_child(Box::new(SetBlackboard::new("a", "k1", "v1")))
        .add_child(Box::new(SetBlackboard::new("b", "k2", "v2")));

    let mut context = BTreeContext::new();

    let result = executor.execute(&mut tree, &mut context).await?;

    assert_eq!(result.status, NodeStatus::Success);
    assert_eq!(result.tick_count, 1);

    Ok(())
}
```

### With Bounds

```rust
use std::time::Duration;

let executor = BTreeExecutor::new()
    .with_max_ticks(100)
    .with_deadline(Duration::from_secs(30));

let result = executor.execute(&mut tree, &mut context).await?;

if result.max_ticks_reached {
    println!("Stopped at {} ticks", result.tick_count);
}

if result.deadline_exceeded {
    println!("Exceeded {:?} deadline", result.duration);
}
```

### With Cancellation

```rust
use tokio::sync::watch;
use tokio::time::{sleep, Duration};

let (cancel_tx, cancel_rx) = watch::channel(false);

tokio::spawn(async move {
    sleep(Duration::from_secs(5)).await;
    cancel_tx.send(true).unwrap();
});

let result = executor
    .execute_with_cancel(&mut tree, &mut context, cancel_rx)
    .await?;

if result.cancelled {
    println!("Execution was cancelled");
}
```

### With Tracing

```rust
// Initialize tracing
tracing_subscriber::fmt::init();

let executor = BTreeExecutor::new()
    .with_tracing(true);

// Logs execution progress
let result = executor.execute(&mut tree, &mut context).await?;
```

### With Visualizer

```rust
use igris_btree::visualizer::TreeVisualizer;

let visualizer = Arc::new(TreeVisualizer::new());

let executor = BTreeExecutor::new()
    .with_visualizer(visualizer.clone());

let result = executor.execute(&mut tree, &mut context).await?;

// Export snapshot

    .export_snapshot(&tree, &context, result.tick_count)
    .await?;
```

### Complete Example

```rust
use igris_btree::prelude::*;
use igris_btree::visualizer::TreeVisualizer;
use std::sync::Arc;
use std::time::Duration;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    tracing_subscriber::fmt::init();

    let visualizer = Arc::new(TreeVisualizer::new());

    let executor = BTreeExecutor::new()
        .with_max_ticks(1000)
        .with_deadline(Duration::from_secs(60))
        .with_tracing(true)
        .with_tick_delay(Duration::from_millis(10))
        .with_visualizer(visualizer.clone());

    let mut tree = Sequence::new("complete_mission")
        .add_child(Box::new(SetBlackboard::new("init", "status", "starting")))
        .add_child(Box::new(SetBlackboard::new("work", "progress", 50)))
        .add_child(Box::new(SetBlackboard::new("done", "status", "completed")));

    let mut context = BTreeContext::new();

    let result = executor.execute(&mut tree, &mut context).await?;

    println!("Execution: {}", result);
    println!("Cancelled: {}", result.cancelled);
    println!("Max ticks reached: {}", result.max_ticks_reached);
    println!("Deadline exceeded: {}", result.deadline_exceeded);

    if !result.errors.is_empty() {
        println!("Errors: {:?}", result.errors);
    }

    let snapshot = visualizer
        .export_snapshot(&tree, &context, result.tick_count)
        .await?;

    println!("Metrics: {:?}", snapshot.metrics);

    Ok(())
}
```

## Testing

### Unit Tests

```rust
#[tokio::test]
async fn test_executor_basic() {
    let executor = BTreeExecutor::new();

    let mut tree = SetBlackboard::new("test", "key", "value");
    let mut context = BTreeContext::new();

    let result = executor.execute(&mut tree, &mut context).await.unwrap();

    assert_eq!(result.tick_count, 1);

#[tokio::test]
async fn test_executor_max_ticks() {
    let executor = BTreeExecutor::new()
        .with_max_ticks(10);

    let mut context = BTreeContext::new();

    let result = executor.execute(&mut tree, &mut context).await.unwrap();

    assert!(result.max_ticks_reached);
    assert_eq!(result.tick_count, 10);
}

#[tokio::test]
async fn test_executor_deadline() {
    let executor = BTreeExecutor::new()
        .with_deadline(Duration::from_millis(100));

    let mut tree = Repeat::new("slow", slow_action(), None);
    let mut context = BTreeContext::new();

    let result = executor.execute(&mut tree, &mut context).await.unwrap();

    assert!(result.deadline_exceeded);
}
```

## Performance Considerations

### Tick Overhead

- **No delay**: Max tick rate limited by node execution time
- **With delay**: Tick rate = 1 / delay (10ms delay = 100 Hz)
- **With visualizer**: +0.1-5ms per tick (depends on tree size)

### Memory Usage

- **Executor**: ~1KB per instance
- **ExecutionResult**: ~200 bytes
- **With visualizer**: +100KB for typical trees

### Recommendations

1. **Development**: Enable all features (tracing, visualizer, bounds)
2. **Production**: Disable tracing, minimal visualizer config
3. **Real-time**: Use deadline for guarantees
4. **Long-running**: Use max_ticks or deadline to prevent hangs
