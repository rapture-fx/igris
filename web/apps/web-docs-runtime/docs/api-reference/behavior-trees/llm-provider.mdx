# LlmProvider API Reference

Complete API reference for the LLM provider trait and implementations.

---

## LlmProvider Trait

The core trait for LLM integration following the BYOM (Bring Your Own Model) philosophy.

### Definition

```rust
#[async_trait]
pub trait LlmProvider: Send + Sync {
    async fn generate(&self, prompt: &str) -> anyhow::Result<String>;
    fn name(&self) -> &str;
    async fn generate_stream(
        &self,
        prompt: &str,
    ) -> anyhow::Result<tokio::sync::mpsc::Receiver<String>>;
}
```

---

## Required Methods

### generate()

```rust
async fn generate(&self, prompt: &str) -> anyhow::Result<String>
```

Generates text from a prompt (synchronous/non-streaming).

**Parameters:**
- `prompt`: Input text prompt

**Returns:**
- `Ok(String)`: Generated text
- `Err(anyhow::Error)`: Generation failed (network, timeout, API error)

**Example:**
```rust
let response = provider.generate("Generate a navigation plan").await?;
println!("Response: {}", response);
```

### name()

```rust
fn name(&self) -> &str
```

Returns provider identifier for logging.

**Returns:** Provider name (e.g., "openai", "ollama", "mock")

**Example:**
```rust
println!("Using provider: {}", provider.name());
```

---

## Optional Methods

### generate_stream()

```rust
async fn generate_stream(
    &self,
    prompt: &str,
) -> anyhow::Result<tokio::sync::mpsc::Receiver<String>>
```

Generates text with streaming (token-by-token).

**Parameters:**
- `prompt`: Input text prompt

**Returns:**
- `Ok(Receiver<String>)`: Channel receiving tokens
- `Err(anyhow::Error)`: Streaming not supported or failed

**Default:** Returns error "Streaming not supported by this provider"

**Example:**
```rust
let mut rx = provider.generate_stream("Write a story").await?;

while let Some(token) = rx.recv().await {
    print!("{}", token);
}
```

## MockLlmProvider

Built-in mock provider for testing and development.

### Definition

```rust
pub struct MockLlmProvider {
    responses: Vec<String>,
    current: std::sync::Mutex<usize>,
}
```

### Construction

#### new()

```rust
pub fn new(responses: Vec<String>) -> Self
```

Creates a mock provider with custom responses.

**Parameters:**
- `responses`: Pre-defined responses (cycles through on each call)

**Example:**
```rust
let provider = MockLlmProvider::new(vec![
    r#"{"type": "Sequence", "name": "plan1", "children": []}"#.to_string(),
    r#"{"type": "Sequence", "name": "plan2", "children": []}"#.to_string(),
]);
```

#### with_navigation_plan()

```rust
pub fn with_navigation_plan() -> Self
```

Creates a mock provider with pre-built navigation plan.

**Returns:** MockLlmProvider configured with navigation sequence

**Example:**
```rust
let provider = MockLlmProvider::with_navigation_plan();
let response = provider.generate("").await?;
// Returns JSON navigation plan
```

**Plan Contents:**
```json
{
  "type": "Sequence",
  "name": "Navigate to warehouse",
  "children": [
    {
      "type": "Action",
      "name": "Move forward",
      "tool": "navigate",
      "args": {"direction": "forward", "distance": 10}
    },
    {
      "type": "Action",
      "name": "Turn right",
      "tool": "navigate",
      "args": {"direction": "right", "angle": 90}
    }
  ]
}
```

#### with_recovery_plan()

```rust
pub fn with_recovery_plan() -> Self
```

Creates a mock provider with recovery plans (for testing ReplanOnFailure).

**Returns:** MockLlmProvider with two plans (primary, recovery)

**Example:**
```rust
let provider = MockLlmProvider::with_recovery_plan();

// First call: primary plan
let plan1 = provider.generate("").await?;

// Second call: recovery plan
let plan2 = provider.generate("").await?;
```

### Behavior

- Cycles through responses on each `generate()` call
- Thread-safe (uses Mutex for counter)
- Returns responses in order, wraps around at end

## Custom Provider Implementation

### Example: Ollama Provider

```rust
use igris_btree::LlmProvider;
use async_trait::async_trait;
use reqwest::Client;
use serde_json::json;

pub struct OllamaProvider {
    client: Client,
    base_url: String,
    model: String,
}

impl OllamaProvider {
    pub fn new(base_url: impl Into<String>, model: impl Into<String>) -> Self {
        Self {
            client: Client::new(),
            base_url: base_url.into(),
            model: model.into(),
        }
    }
}

#[async_trait]
impl LlmProvider for OllamaProvider {
    async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
        let response = self.client
            .post(format!("{}/api/generate", self.base_url))
            .json(&json!({
                "model": self.model,
                "prompt": prompt,
                "stream": false
            }))
            .send()
            .await?;

        let data: serde_json::Value = response.json().await?;
        let text = data["response"]
            .as_str()
            .ok_or_else(|| anyhow::anyhow!("No response field"))?;

        Ok(text.to_string())
    }

    fn name(&self) -> &str {
        "ollama"
    }
}
```

### Example: OpenAI Provider

```rust
use igris_btree::LlmProvider;
use async_trait::async_trait;
use reqwest::Client;
use serde_json::json;

pub struct OpenAIProvider {
    client: Client,
    api_key: String,
    model: String,
}

impl OpenAIProvider {
    pub fn new(api_key: impl Into<String>, model: impl Into<String>) -> Self {
        Self {
            client: Client::new(),
            api_key: api_key.into(),
            model: model.into(),
        }
    }
}

#[async_trait]
impl LlmProvider for OpenAIProvider {
    async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
        let response = self.client
            .post("https://api.openai.com/v1/chat/completions")
            .header("Authorization", format!("Bearer {}", self.api_key))
            .json(&json!({
                "model": self.model,
                "messages": [{
                    "role": "user",
                    "content": prompt
                }],
                "temperature": 0.7
            }))
            .send()
            .await?;

        let data: serde_json::Value = response.json().await?;
        let text = data["choices"][0]["message"]["content"]
            .as_str()
            .ok_or_else(|| anyhow::anyhow!("No content in response"))?;

        Ok(text.to_string())
    }

    fn name(&self) -> &str {
        "openai"
    }

    async fn generate_stream(
        &self,
        prompt: &str,
    ) -> anyhow::Result<tokio::sync::mpsc::Receiver<String>> {
        let (tx, rx) = tokio::sync::mpsc::channel(100);

            .header("Authorization", format!("Bearer {}", self.api_key))
            .json(&json!({
                "model": self.model,
                "messages": [{"role": "user", "content": prompt}],
                "stream": true
            }))
            .send()
            .await?;

        });

        Ok(rx)
    }
}
```

## Usage Examples

### Basic Usage

```rust
use igris_btree::prelude::*;
use std::sync::Arc;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Create provider
    let provider = Arc::new(MockLlmProvider::with_navigation_plan());

    // Create context with provider
    let mut context = BTreeContext::new().with_llm(provider);

    // Use in LLMPlannerNode
    context.blackboard.set("task", "Navigate to warehouse").await;

    let mut planner = LLMPlannerNode::new("planner", "task", "plan");
    let status = planner.tick(&mut context).await?;

    assert_eq!(status, NodeStatus::Success);

    Ok(())
}
```

### With Custom Provider

```rust
let provider = Arc::new(OllamaProvider::new(
    "http://localhost:11434",
    "phi3"
));

let mut context = BTreeContext::new().with_llm(provider);

// Now LLM nodes will use Ollama
```

### Testing with Mock

```rust
#[tokio::test]
async fn test_llm_planning() {
    let provider = Arc::new(MockLlmProvider::new(vec![
        r#"{"type": "Action", "name": "test", "tool": "test_tool", "args": {}}"#.to_string()
    ]));

    let mut context = BTreeContext::new().with_llm(provider);
    context.blackboard.set("task", "Test task").await;

    let mut planner = LLMPlannerNode::new("planner", "task", "plan");
    let status = planner.tick(&mut context).await.unwrap();

    assert_eq!(status, NodeStatus::Success);
    assert!(context.blackboard.contains("plan").await);
}
```

### Checking Provider

```rust
if context.has_llm() {
    println!("LLM provider configured");

    if let Some(provider) = context.llm_provider() {
        println!("Provider: {}", provider.name());
    }
} else {
    println!("No LLM provider - LLM nodes will fail");
}
```

## Provider Best Practices

### 1. Error Handling

Return descriptive errors:

```rust
async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
    let response = self.client.post(url)
        .send()
        .await
        .map_err(|e| anyhow::anyhow!("Network error: {}", e))?;

    if !response.status().is_success() {
        anyhow::bail!("API error: {}", response.status());
    }

    // Process response...
}
```

### 2. Timeouts

Set reasonable timeouts:

```rust
use tokio::time::timeout;

async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
    let future = self.client.post(url).send();

    let response = timeout(Duration::from_secs(30), future)
        .await
        .map_err(|_| anyhow::anyhow!("LLM timeout"))?
        .map_err(|e| anyhow::anyhow!("Request failed: {}", e))?;

    // Process response...
}
```

### 3. Retries

Implement retry logic:

```rust
async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
    let max_retries = 3;

    for attempt in 0..max_retries {
        match self.try_generate(prompt).await {
            Ok(response) => return Ok(response),
            Err(e) if attempt < max_retries - 1 => {
                eprintln!("Attempt {} failed: {}", attempt + 1, e);
                tokio::time::sleep(Duration::from_secs(1 << attempt)).await;
            }
            Err(e) => return Err(e),
        }
    }

    unreachable!()
}
```

### 4. Logging

Log requests and responses:

```rust
use tracing::{info, debug, error};

async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
    info!("LLM request to {}", self.name());
    debug!("Prompt: {}", prompt);

    let start = Instant::now();

    match self.call_api(prompt).await {
        Ok(response) => {
            let duration = start.elapsed();
            info!("LLM response in {:?}", duration);
            debug!("Response: {}", response);
            Ok(response)
        }
        Err(e) => {
            error!("LLM error: {}", e);
            Err(e)
        }
    }
}
```

### 5. Cost Tracking

Track usage and costs:

```rust
use std::sync::atomic::{AtomicU64, Ordering};

pub struct MeteredProvider {
    inner: Arc<dyn LlmProvider>,
    calls: AtomicU64,
    tokens: AtomicU64,
}

impl MeteredProvider {
    pub fn stats(&self) -> (u64, u64) {
        (
            self.calls.load(Ordering::Relaxed),
            self.tokens.load(Ordering::Relaxed)
        )
    }
}

#[async_trait]
impl LlmProvider for MeteredProvider {
    async fn generate(&self, prompt: &str) -> anyhow::Result<String> {
        self.calls.fetch_add(1, Ordering::Relaxed);

        let response = self.inner.generate(prompt).await?;

        let tokens = estimate_tokens(prompt) + estimate_tokens(&response);
        self.tokens.fetch_add(tokens, Ordering::Relaxed);

        Ok(response)
    }

    fn name(&self) -> &str {
        "metered"
    }
}
```

## Testing Strategies

### Unit Tests with Mock

```rust
#[tokio::test]
async fn test_provider_generate() {
    let provider = MockLlmProvider::new(vec![
        "response 1".to_string(),
        "response 2".to_string(),
    ]);

    let r1 = provider.generate("prompt 1").await.unwrap();
    assert_eq!(r1, "response 1");

    let r2 = provider.generate("prompt 2").await.unwrap();
    assert_eq!(r2, "response 2");

    // Wraps around
    let r3 = provider.generate("prompt 3").await.unwrap();
    assert_eq!(r3, "response 1");
}
```

## Thread Safety

All providers must be `Send + Sync`:

- Safe to share across threads
- Safe for concurrent calls
- Use interior mutability for state (Mutex, RwLock, Atomic)
