# Streaming

The execution engine supports server-sent events (SSE) streaming for chat completions, compatible with the OpenAI streaming format.

---

## Enabling Streaming

Set `"stream": true` in your request body:

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "stream": true,
    "messages": [{"role": "user", "content": "Write a haiku about edge computing."}]
  }'
```

---

## Stream Format

The response is a sequence of `data:` lines in SSE format:

```
data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","choices":[{"delta":{"role":"assistant"},"index":0,"finish_reason":null}]}

data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","choices":[{"delta":{"content":"Data"},"index":0,"finish_reason":null}]}

data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","choices":[{"delta":{"content":" flows"},"index":0,"finish_reason":null}]}

data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","choices":[{"delta":{"content":" at the edge,"},"index":0,"finish_reason":null}]}

data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","choices":[{"delta":{},"index":0,"finish_reason":"stop"}]}

data: [DONE]
```

Each chunk contains a partial `delta` with incremental content. The stream ends with `data: [DONE]`.

When the request is being executed through the durable Runtime task path, the stream may also include a terminal `task_result` event before `[DONE]`:

```text
event: task_result
data: {"task_id":"018f4a2b-3c1e-7a2d-9b8f-4d5e6f7a8b9c","steps_completed":1,"steps_total":1,"status":"completed","checkpoint":{"resume_token":{"last_committed_step":0}},"usage":{"prompt_tokens":42,"completion_tokens":18,"total_tokens":60},"execution_envelope":{"execution_id":"exec-..."},"execution_receipt":{"transaction_id":"tx-..."}}
```

Use that event when you need the final durable-task outcome, signed execution artifacts, or checkpoint metadata directly from the stream session.

Current durable-streaming scope:

- base streaming
- all named speculative streaming modes
- council mode streaming

Council-mode streaming emits the synthesized final answer over SSE and still includes the terminal `task_result` event for the durable task outcome.

## SDK Examples

### Python (OpenAI SDK)

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="not-required"
)

stream = client.chat.completions.create(
    model="phi3",
    messages=[{"role": "user", "content": "Write a haiku about edge computing."}],
    stream=True,
)

for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

### JavaScript / TypeScript

```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'http://localhost:8080/v1',
  apiKey: 'not-required',
});

const stream = await client.chat.completions.create({
  model: 'phi3',
  messages: [{ role: 'user', content: 'Write a haiku about edge computing.' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? '');
}
```

### Native JavaScript SDK

```typescript
import { IgrisClient } from '@igris-inertial/javascript-sdk';

const client = new IgrisClient({
  baseUrl: 'https://overture.igrisinertial.com',
  apiKey: process.env.IGRIS_API_KEY,
});

for await (const event of client.streamInference({
  model: 'gpt-4.1-mini',
  messages: [{ role: 'user', content: 'Summarize today\\'s deployment risk.' }],
})) {
  if (event.type === 'chunk') {
    process.stdout.write(
      String(
        ((event.data.choices as Array<{ delta?: { content?: string } }> | undefined)?.[0]?.delta?.content) ?? ''
      )
    );
  }

  if (event.type === 'task_result') {
    console.log('\\nDurable task:', event.data.task_id);
    console.log('Status:', event.data.status);
  }
}
```

### Go

```go
stream, err := client.Chat.Completions.NewStreaming(ctx, openai.ChatCompletionNewParams{
    Model: openai.F("phi3"),
    Messages: openai.F([]openai.ChatCompletionMessageParamUnion{
        openai.UserMessage("Write a haiku about edge computing."),
    }),
})

for stream.Next() {
    chunk := stream.Current()
    if len(chunk.Choices) > 0 {
        fmt.Print(chunk.Choices[0].Delta.Content)
    }
}
```

### curl with raw SSE

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{"model": "phi3", "stream": true, "messages": [{"role": "user", "content": "Hello"}]}' \
  --no-buffer
```

## Streaming with Modes

Streaming is supported in all request modes. For reflection and planning modes, chunks are emitted as each stage completes:

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "mode": "reflection",
    "stream": true,
    "messages": [{"role": "user", "content": "Explain Byzantine fault tolerance."}]
  }'
```

In reflection mode, the stream may pause between the initial generation and the critique/regeneration phases.

---

## Error Handling

If a streaming request fails after the stream has started, the engine emits an error chunk before closing. Durable streamed runs may also emit a `task_result` event describing the terminal failed task response before the error event:

```
data: {"error": {"message": "Provider timed out", "type": "provider_error", "code": "timeout"}}

data: [DONE]
```

Always handle the case where `chunk.choices` may be empty or `finish_reason` is `"error"`.
