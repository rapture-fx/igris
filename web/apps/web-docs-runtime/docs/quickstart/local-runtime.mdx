# Local Runtime Quick Start

Get Igris Runtime running locally and make your first AI call in under 2 minutes.

---

## Step 1: Install the Runtime Binary

### macOS (Homebrew)

```bash
brew tap igris-inertial/tap
brew install igris-runtime
```

### Linux (curl)

```bash
curl -fsSL https://get.igrisinertial.com/runtime | sh
```

### From Source

```bash
git clone https://github.com/Igris-inertial/system.git
cd system/igris-runtime
cargo build --release
```

Verify the installation:

```bash
igris-runtime --version
# => igris-runtime 1.6.0
```

---

## Step 2: Start the Runtime

Launch the runtime server with a single command:

```bash
igris-runtime serve
```

**Expected output:**

```
Igris Runtime v1.6 starting...
Server listening on 0.0.0.0:8080
Health endpoint: http://localhost:8080/v1/health
Local LLM fallback: ENABLED
Ready to accept requests.
```

The runtime is now listening on port 8080 with default settings. To customize the port or other options:

```bash
igris-runtime serve --port 9090 --host 127.0.0.1
```

---

## Step 3: Verify with a Health Check

Confirm the runtime is running:

```bash
curl http://localhost:8080/v1/health
```

**Response:**

```json
{
  "status": "ok",
  "version": "1.6.0",
  "uptime_seconds": 12,
  "local_llm_available": true,
  "providers_configured": 0
}
```

---

## Step 4: Connect via SDK

### Python

Install the SDK and connect to your local runtime:

```bash
pip install igris-inertial
```

```python
from igris import Runtime

# Connect to local runtime
runtime = Runtime(base_url="http://localhost:8080")

# Check health
health = runtime.health()
print(f"Runtime status: {health['status']}")
print(f"Local LLM available: {health['local_llm_available']}")

# Make a chat request
response = runtime.chat(
    model="phi3",
    messages=[{"role": "user", "content": "What is 2+2?"}]
)

print(response.choices[0].message.content)
# => "2+2 equals 4."
```

### JavaScript/TypeScript

```bash
npm install @igris-inertial/sdk
```

```typescript
import { Runtime } from '@igris-inertial/sdk';

// Connect to local runtime
const runtime = new Runtime({ baseUrl: 'http://localhost:8080' });

// Check health
const health = await runtime.health();
console.log(`Runtime status: ${health.status}`);

// Make a chat request
const response = await runtime.chat({
  model: 'phi3',
  messages: [{ role: 'user', content: 'What is 2+2?' }],
});

console.log(response.choices[0].message.content);
// => "2+2 equals 4."
```

## Step 5: Make a Local Chat Call

With the runtime running and a local model loaded, every call is served on-device with zero cloud dependency:

### Python

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

# Streaming response
for chunk in runtime.chat(
    model="phi3",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain gravity in one sentence."},
    ],
    stream=True,
):
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

print()  # newline after stream
```

### JavaScript/TypeScript

```typescript
const stream = await runtime.chat({
  model: 'phi3',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Explain gravity in one sentence.' },
  ],
  stream: true,
});

for await (const chunk of stream) {
  const content = chunk.choices[0]?.delta?.content;
  if (content) process.stdout.write(content);
}
```

## What Just Happened

1. You installed the `igris-runtime` binary.
2. You started the runtime with `igris-runtime serve`.
3. You verified it was healthy with a GET to `/v1/health`.
4. You connected a Python or JavaScript SDK using the `Runtime` class.
5. You made a local chat request -- fully on-device, no cloud required.
