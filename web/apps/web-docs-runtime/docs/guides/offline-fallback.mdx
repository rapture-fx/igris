# Offline Fallback

Configure the runtime for automatic cloud-to-local failover so your AI keeps working without internet.

---

## Overview

Igris Runtime supports an offline-first architecture where cloud providers are preferred when available, but a local on-device model takes over automatically when the network is unreachable. This tutorial covers:

1. Configuring the runtime with local and cloud providers
2. Demonstrating automatic fallback behavior
3. Building offline-first application patterns
4. Monitoring fallback events

---

## Step 1: Configure Local + Cloud Providers

Create a `config.json5` that includes both cloud and local providers:

```json5
{
  server: {
    host: "0.0.0.0",
    port: 8080
  },

  // Cloud providers (tried first)
  providers: [
    {
      name: "openai",
      api_key: "${OPENAI_API_KEY}",
      base_url: "https://api.openai.com/v1",
      models: ["gpt-4", "gpt-4o", "gpt-3.5-turbo"],
      timeout_ms: 5000,    // 5 second timeout before fallback
      max_retries: 1
    },
    {
      name: "anthropic",
      api_key: "${ANTHROPIC_API_KEY}",
      base_url: "https://api.anthropic.com/v1",
      models: ["claude-3-opus", "claude-3-sonnet"],
      timeout_ms: 5000,
      max_retries: 1
    }
  ],

  // Local fallback (used when all cloud providers fail)
  local_fallback: {
    enabled: true,
    model_path: "models/phi-3-mini-4k-instruct-q4.gguf",
    context_size: 4096,
    threads: 4,
    max_tokens: 512,
    temperature: 0.7,
    cost_per_1k_tokens: 0.0
  },

  // Routing configuration
  routing: {
    speculative: {
      enabled: true,
      max_providers: 3,
      first_token_timeout_ms: 5000
    },
    fallback: {
      // Trigger fallback after this many consecutive cloud failures
      consecutive_failures_threshold: 2,
      // How long to stay in fallback mode before retrying cloud
      cooldown_secs: 60,
      // Log every fallback event
      log_events: true
    }
  }
}
```

Start the runtime:

```bash
igris-runtime serve --config config.json5
```

**Expected output:**

```
Igris Runtime v1.6 starting...
Provider registered: openai (3 models)
Provider registered: anthropic (2 models)
Local LLM provider initialized: phi-3-mini-4k-instruct-q4.gguf
Local LLM fallback: ENABLED
Server listening on 0.0.0.0:8080
```

## Step 2: Demonstrate Automatic Fallback

### Normal Operation (Cloud Available)

When the internet is working, requests go to the cloud provider:

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

response = runtime.chat(
    model="gpt-4",
    messages=[{"role": "user", "content": "What is quantum computing?"}],
)

print(response.choices[0].message.content)
print(f"Provider used: {response.metadata.provider}")
# => Provider used: openai
print(f"Fallback used: {response.metadata.fallback_used}")
# => Fallback used: False
```

### Offline Operation (Cloud Unavailable)

Disconnect your network and make the same request:

```python
response = runtime.chat(
    model="gpt-4",
    messages=[{"role": "user", "content": "What is quantum computing?"}],
)

print(response.choices[0].message.content)
# Still returns a response, but from local model
print(f"Provider used: {response.metadata.provider}")
# => Provider used: local
print(f"Fallback used: {response.metadata.fallback_used}")
# => Fallback used: True
print(f"Original model: {response.metadata.requested_model}")
# => Original model: gpt-4
print(f"Actual model: {response.model}")
# => Actual model: phi3
```

The same code works in both scenarios. No changes needed.

### JavaScript Example

```typescript
import { Runtime } from '@igris-inertial/sdk';

const runtime = new Runtime({ baseUrl: 'http://localhost:8080' });

const response = await runtime.chat({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'What is quantum computing?' }],
});

console.log(response.choices[0].message.content);
console.log(`Provider: ${response.metadata?.provider}`);
console.log(`Fallback: ${response.metadata?.fallbackUsed}`);
```

## Step 3: Offline-First Application Patterns

### Pattern 1: Graceful Degradation with Fallback Awareness

Adjust your application behavior based on whether the fallback was triggered:

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

def answer_question(question: str) -> dict:
    response = runtime.chat(
        model="gpt-4",
        messages=[{"role": "user", "content": question}],
    )

    result = {
        "answer": response.choices[0].message.content,
        "provider": response.metadata.provider,
        "is_offline": response.metadata.fallback_used,
    }

    if response.metadata.fallback_used:
        result["disclaimer"] = (
            "This response was generated by an on-device model "
            "while offline. Quality may differ from cloud responses."
        )

    return result
```

### Pattern 2: Model-Aware Prompting

Send different prompts based on whether you expect local or cloud processing:

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

def smart_query(question: str) -> str:
    # Check if cloud is available
    health = runtime.health()
    cloud_available = health.get("providers_available", 0) > 0

    if cloud_available:
        # Full prompt for capable cloud model
        messages = [
            {"role": "system", "content": "You are an expert assistant. Provide detailed, nuanced answers."},
            {"role": "user", "content": question},
        ]
        model = "gpt-4"
    else:
        # Simpler prompt for local model
        messages = [
            {"role": "system", "content": "Answer concisely in 2-3 sentences."},
            {"role": "user", "content": question},
        ]
        model = "phi3"

    response = runtime.chat(model=model, messages=messages)
    return response.choices[0].message.content
```

### Pattern 3: Offline Queue with Sync

Queue requests when offline and re-process with the cloud model when connectivity returns:

```python
from igris import Runtime
import json
import time

runtime = Runtime(base_url="http://localhost:8080")
offline_queue = []

def query_with_queue(question: str) -> str:
    response = runtime.chat(
        model="gpt-4",
        messages=[{"role": "user", "content": question}],
    )

    if response.metadata.fallback_used:
        # Save to queue for cloud reprocessing later
        offline_queue.append({
            "question": question,
            "offline_answer": response.choices[0].message.content,
            "timestamp": time.time(),
        })

    return response.choices[0].message.content

def sync_offline_queue():
    """Re-process queued items with cloud model when back online."""
    health = runtime.health()
    if health.get("providers_available", 0) == 0:
        print("Still offline, skipping sync.")
        return

    for item in offline_queue:
        response = runtime.chat(
            model="gpt-4",
            messages=[{"role": "user", "content": item["question"]}],
        )
        if not response.metadata.fallback_used:
            item["cloud_answer"] = response.choices[0].message.content
            print(f"Synced: {item['question'][:50]}...")

    # Remove synced items
    offline_queue[:] = [i for i in offline_queue if "cloud_answer" not in i]
```

### Pattern 4: Pre-Cache Critical Responses

For mission-critical scenarios, pre-cache responses while online so they are available instantly when offline:

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

# Pre-cache critical prompts while online
critical_prompts = [
    "What is the emergency shutdown procedure?",
    "How do I reset the navigation system?",
    "What are the safety protocols for warehouse zone A?",
]

cache = {}

def pre_cache():
    for prompt in critical_prompts:
        response = runtime.chat(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
        )
        if not response.metadata.fallback_used:
            cache[prompt] = response.choices[0].message.content
            print(f"Cached: {prompt[:50]}...")

def get_answer(question: str) -> str:
    # Check cache first
    if question in cache:
        return cache[question]

    # Otherwise query runtime (cloud or local fallback)
    response = runtime.chat(
        model="gpt-4",
        messages=[{"role": "user", "content": question}],
    )
    return response.choices[0].message.content
```

### Programmatic Event Monitoring

**Python:**

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

# Poll fallback status
health = runtime.health()
print(f"Fallback active: {health.get('fallback_active')}")
print(f"Total activations: {health.get('fallback_activations_total')}")
print(f"Cloud providers available: {health.get('providers_available')}")

# Stream runtime events
for event in runtime.events(stream=True):
    if event.type == "fallback_activated":
        print(f"[FALLBACK] Activated at {event.timestamp}")
        print(f"  Reason: {event.reason}")
        print(f"  Failed provider: {event.failed_provider}")
    elif event.type == "fallback_deactivated":
        print(f"[RECOVERY] Cloud provider restored at {event.timestamp}")
        print(f"  Provider: {event.provider}")
        print(f"  Downtime: {event.downtime_secs:.1f}s")
```

**JavaScript:**

```typescript
import { Runtime } from '@igris-inertial/sdk';

const runtime = new Runtime({ baseUrl: 'http://localhost:8080' });

// Check fallback status
const health = await runtime.health();
console.log(`Fallback active: ${health.fallbackActive}`);
console.log(`Total activations: ${health.fallbackActivationsTotal}`);

// Stream events
for await (const event of runtime.events()) {
  if (event.type === 'fallback_activated') {
    console.log(`[FALLBACK] Reason: ${event.reason}`);
  } else if (event.type === 'fallback_deactivated') {
    console.log(`[RECOVERY] Provider restored: ${event.provider}`);
  }
}
```

## Configuration Reference

All fallback-related settings:

```json5
{
  local_fallback: {
    enabled: true,                    // Enable local fallback
    model_path: "models/phi-3.gguf", // Path to GGUF model
    context_size: 4096,              // Context window size
    threads: 4,                      // CPU threads for inference
    max_tokens: 512,                 // Maximum output tokens
    temperature: 0.7,                // Sampling temperature
    cost_per_1k_tokens: 0.0          // Cost tracking
  },

  routing: {
    speculative: {
      enabled: true,                 // Try multiple providers simultaneously
      max_providers: 3,              // Maximum concurrent provider attempts
      first_token_timeout_ms: 5000   // Timeout before local fallback
    },
    fallback: {
      consecutive_failures_threshold: 2,  // Failures before entering fallback mode
      cooldown_secs: 60,                  // Seconds in fallback before retrying cloud
      log_events: true                    // Log all fallback events
    }
  }
}
```
