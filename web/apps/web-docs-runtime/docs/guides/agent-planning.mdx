# Agent Planning and Reflection

Build planning agents that reason, execute, and improve using LLM nodes and behavior trees.

---

## Overview

This tutorial covers:

1. Defining a planning agent with LLMNodes
2. Chaining planning, execution, and reflection stages
3. Using a behavior tree for the agent loop
4. Iterating until a quality threshold is met

**Prerequisites:**

- Igris Runtime running locally
- A local model loaded (Phi-3, Mistral, or similar)
- Python SDK (`pip install igris-inertial`) or JS SDK (`npm install @igris-inertial/sdk`)

---

## How Planning Agents Work

A planning agent follows a four-phase loop:

```
Plan --> Execute --> Observe --> Reflect --> (repeat or finish)
```

1. **Plan:** The LLM generates a step-by-step plan from the user's goal.
2. **Execute:** The runtime executes each step (tool calls, navigation, queries).
3. **Observe:** Results are captured in the blackboard.
4. **Reflect:** The LLM reviews the results, scores quality, and decides whether to iterate.

This loop is expressed as a behavior tree, giving you deterministic control over an inherently non-deterministic process.

## Step 1: Define the Planning Agent

Create `planning_agent.yaml`:

```yaml
name: planning_agent
type: sequence
children:
  # Stage 1: Accept the goal
  - name: set_goal
    type: action
    action: set_blackboard
    params:
      key: agent_goal
      value: "Research the top 3 competitors in the robotics middleware space and summarize their strengths and weaknesses."

  # Stage 2: Generate the plan
  - name: generate_plan
    type: llm_node
    prompt_key: agent_goal
    output_key: execution_plan
    system_prompt: |
      You are a planning agent. Given a goal, break it into 3-5 concrete steps.
      Output a JSON array of step objects with "step_number", "description",
      and "action" fields. The action field should be one of:
      search, analyze, summarize, compare.

      Example output:
      [
        {"step_number": 1, "description": "Search for competitors", "action": "search"},
        {"step_number": 2, "description": "Analyze each competitor", "action": "analyze"},
        {"step_number": 3, "description": "Summarize findings", "action": "summarize"}
      ]

  # Stage 3: Execute the plan
  - name: execute_plan
    type: subtree_loader
    plan_key: execution_plan

  # Stage 4: Reflect on results
  - name: reflect_on_results
    type: llm_node
    prompt_key: execution_results
    output_key: reflection
    system_prompt: |
      You are a reflection agent. Review the execution results and score
      the quality from 0.0 to 1.0. Output a JSON object with:
      - "score": float between 0.0 and 1.0
      - "critique": string describing what could be improved
      - "should_retry": boolean

  # Stage 5: Check quality
  - name: quality_gate
    type: condition
    condition: blackboard_json_field_gte
    params:
      key: reflection
      field: score
      value: 0.7
```

## Step 2: Add the Reflection Loop

Wrap the plan-execute-reflect cycle in a retry decorator so the agent iterates until quality is sufficient:

```yaml
name: planning_agent_with_loop
type: sequence
children:
  - name: set_goal
    type: action
    action: set_blackboard
    params:
      key: agent_goal
      value: "Research the top 3 competitors in the robotics middleware space and summarize their strengths and weaknesses."

  - name: set_iteration
    type: action
    action: set_blackboard
    params:
      key: iteration
      value: 0

  # The core plan-execute-reflect loop, retried up to 3 times
  - name: agent_loop
    type: decorator
    decorator: retry
    max_attempts: 3
    child:
      name: plan_execute_reflect
      type: sequence
      children:
        - name: increment_iteration
          type: action
          action: increment_blackboard
          params:
            key: iteration

        # Planning phase
        - name: plan
          type: llm_node
          prompt_key: agent_goal
          output_key: execution_plan
          context_keys:
            - reflection  # Include previous reflection if available
            - iteration
          system_prompt: |
            You are a planning agent. Given a goal and optional previous
            reflection feedback, create an improved step-by-step plan.
            If this is a retry, address the critique from the previous attempt.
            Output a JSON array of step objects.

        # Execution phase
        - name: execute
          type: subtree_loader
          plan_key: execution_plan

        # Reflection phase
        - name: reflect
          type: llm_node
          prompt_key: execution_results
          output_key: reflection
          system_prompt: |
            Review the execution results. Score quality 0.0-1.0.
            Output JSON: {"score": float, "critique": string, "should_retry": bool}

        # Quality gate - fails if score < 0.7, triggering retry
        - name: quality_check
          type: condition
          condition: blackboard_json_field_gte
          params:
            key: reflection
            field: score
            value: 0.7

  # Final output
  - name: format_output
    type: llm_node
    prompt_key: execution_results
    output_key: final_answer
    system_prompt: |
      Synthesize the execution results into a clear, well-structured
      final answer. Include key findings, comparisons, and recommendations.
```

## Step 3: Run the Planning Agent

### Python

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

result = runtime.execute_btree(
    tree="planning_agent_with_loop",
    tree_yaml=open("planning_agent.yaml").read(),
    max_ticks=5000,
    timeout_secs=600,
    llm_config={
        "model": "phi3",
        "temperature": 0.4,
        "max_tokens": 2048,
    },
)

print(f"Status: {result.status}")
print(f"Iterations: {result.blackboard.get('iteration')}")

# Get reflection details
import json
reflection = json.loads(result.blackboard.get("reflection", "{}"))
print(f"Final score: {reflection.get('score')}")
print(f"Critique: {reflection.get('critique')}")

# Get the final answer
print(f"\nFinal answer:\n{result.blackboard.get('final_answer')}")
```

### JavaScript

```typescript
import { Runtime } from '@igris-inertial/sdk';
import { readFileSync } from 'fs';

const runtime = new Runtime({ baseUrl: 'http://localhost:8080' });

const result = await runtime.executeBtree({
  tree: 'planning_agent_with_loop',
  treeYaml: readFileSync('planning_agent.yaml', 'utf-8'),
  maxTicks: 5000,
  timeoutSecs: 600,
  llmConfig: {
    model: 'phi3',
    temperature: 0.4,
    maxTokens: 2048,
  },
});

console.log(`Status: ${result.status}`);
console.log(`Iterations: ${result.blackboard.iteration}`);

const reflection = JSON.parse(result.blackboard.reflection ?? '{}');
console.log(`Final score: ${reflection.score}`);

console.log(`\nFinal answer:\n${result.blackboard.final_answer}`);
```

## Step 4: Using the HTTP API Directly

You can also invoke the planning mode through the chat completions endpoint without a YAML tree:

```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "phi3",
    "mode": "planning",
    "messages": [
      {
        "role": "user",
        "content": "Research the top 3 competitors in robotics middleware."
      }
    ],
    "planning_config": {
      "max_steps": 5,
      "enable_reflection": true,
      "quality_threshold": 0.7,
      "max_iterations": 3
    }
  }'
```

**Response:**

```json
{
  "choices": [{
    "message": {
      "content": "Here is the competitive analysis..."
    }
  }],
  "planning_result": {
    "goal": "Research the top 3 competitors in robotics middleware",
    "iterations": 2,
    "final_score": 0.85,
    "steps": [
      {
        "step_number": 1,
        "thought": "Need to identify the main players",
        "action": "search",
        "observation": "Found ROS2, NVIDIA Isaac, and Clearpath",
        "reflection": "Good coverage of major platforms"
      }
    ],
    "success": true
  }
}
```

## Advanced Patterns

### Chain Multiple Agents

Create a pipeline where one agent's output feeds the next:

```yaml
name: agent_pipeline
type: sequence
children:
  - name: research_agent
    type: llm_node
    prompt_key: research_goal
    output_key: research_results
    system_prompt: "You are a research agent. Gather comprehensive data."

  - name: analysis_agent
    type: llm_node
    prompt_key: research_results
    output_key: analysis
    system_prompt: "You are an analysis agent. Identify patterns and insights."

  - name: writing_agent
    type: llm_node
    prompt_key: analysis
    output_key: final_report
    system_prompt: "You are a writing agent. Produce a clear, structured report."
```

### Agent with Tool Use

Combine planning with tool execution for real-world actions:

```yaml
name: tool_using_agent
type: sequence
children:
  - name: plan_with_tools
    type: llm_node
    prompt_key: agent_goal
    output_key: tool_plan
    system_prompt: |
      Plan a sequence of actions. Available tools:
      - http_get(url): Fetch data from a URL
      - http_post(url, body): Send data to a URL
      - file_read(path): Read a local file
      - file_write(path, content): Write a local file
      Output a JSON behavior tree using these tools.

  - name: execute_with_tools
    type: subtree_loader
    plan_key: tool_plan

  - name: reflect_on_tool_results
    type: llm_node
    prompt_key: execution_results
    output_key: tool_reflection
    system_prompt: "Review the tool execution results. Did we achieve the goal?"
```

### Parallel Agent Debate

Two agents reason independently, then a judge synthesizes:

```yaml
name: agent_debate
type: sequence
children:
  - name: parallel_reasoning
    type: parallel
    success_threshold: 2
    children:
      - name: agent_alpha
        type: llm_node
        prompt_key: debate_topic
        output_key: alpha_argument
        system_prompt: "You are Agent Alpha. Argue FOR the proposition."

      - name: agent_beta
        type: llm_node
        prompt_key: debate_topic
        output_key: beta_argument
        system_prompt: "You are Agent Beta. Argue AGAINST the proposition."

  - name: judge
    type: llm_node
    prompt_key: combined_arguments
    output_key: verdict
    context_keys:
      - alpha_argument
      - beta_argument
    system_prompt: |
      You are a judge. Review both arguments. Identify the strongest
      points from each side. Produce a balanced synthesis.
```

## Configuration Reference

Planning agent settings in `config.json5`:

```json5
{
  planning: {
    enabled: true,
    max_steps: 10,           // Maximum planning steps per iteration
    enable_reflection: true, // Enable the reflection phase
    quality_threshold: 0.7,  // Minimum quality score to accept
    max_iterations: 3,       // Maximum plan-execute-reflect cycles
    enable_tools: true,      // Allow tool use during execution
    max_tool_calls: 20       // Maximum tool invocations
  }
}
```
