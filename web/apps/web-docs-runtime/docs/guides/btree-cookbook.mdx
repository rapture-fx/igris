# BTree Cookbook

Five practical behavior tree patterns with YAML definitions and SDK code to run them.

---

## Prerequisites

- Igris Runtime running locally (`igris-runtime serve`)
- Python SDK (`pip install igris-inertial`) or JS SDK (`npm install @igris-inertial/sdk`)

---

## 1. Simple Patrol Sequence

A robot patrols three waypoints in order. If any waypoint fails, the entire patrol stops.

### YAML Definition

```yaml
name: patrol_sequence
type: sequence
children:
  - name: go_to_waypoint_a
    type: action
    action: navigate
    params:
      x: 1.0
      y: 0.0
      label: "Waypoint A"

  - name: go_to_waypoint_b
    type: action
    action: navigate
    params:
      x: 3.0
      y: 2.0
      label: "Waypoint B"

  - name: go_to_waypoint_c
    type: action
    action: navigate
    params:
      x: 0.0
      y: 4.0
      label: "Waypoint C"

  - name: report_patrol_complete
    type: action
    action: set_blackboard
    params:
      key: patrol_status
      value: "completed"
```

### Run with Python SDK

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

result = runtime.execute_btree(
    tree="patrol_sequence",
    tree_yaml=open("patrol_sequence.yaml").read(),
    max_ticks=200,
    timeout_secs=60,
)

print(f"Status: {result.status}")
print(f"Ticks: {result.tick_count}")
print(f"Blackboard: {result.blackboard}")
```

### Run with JavaScript SDK

```typescript
import { Runtime } from '@igris-inertial/sdk';
import { readFileSync } from 'fs';

const runtime = new Runtime({ baseUrl: 'http://localhost:8080' });

const result = await runtime.executeBtree({
  tree: 'patrol_sequence',
  treeYaml: readFileSync('patrol_sequence.yaml', 'utf-8'),
  maxTicks: 200,
  timeoutSecs: 60,
});

console.log(`Status: ${result.status}`);
console.log(`Ticks: ${result.tickCount}`);
```

## 2. Search with Fallback

Search the primary area first. If the target is not found, fall back to a secondary area. Uses a `selector` node so the first successful child short-circuits the rest.

### YAML Definition

```yaml
name: search_with_fallback
type: selector
children:
  - name: search_primary_area
    type: sequence
    children:
      - name: navigate_to_primary
        type: action
        action: navigate
        params:
          x: 5.0
          y: 5.0
          label: "Primary Search Zone"

      - name: scan_primary
        type: action
        action: scan_area
        params:
          radius: 3.0
          target: "package_42"

  - name: search_secondary_area
    type: sequence
    children:
      - name: navigate_to_secondary
        type: action
        action: navigate
        params:
          x: 10.0
          y: 2.0
          label: "Secondary Search Zone"

      - name: scan_secondary
        type: action
        action: scan_area
        params:
          radius: 5.0
          target: "package_42"

  - name: report_not_found
    type: action
    action: set_blackboard
    params:
      key: search_result
      value: "target_not_found"
```

### Run with Python SDK

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

result = runtime.execute_btree(
    tree="search_with_fallback",
    tree_yaml=open("search_with_fallback.yaml").read(),
    max_ticks=500,
    timeout_secs=120,
    blackboard={"target_id": "package_42"},
)

print(f"Status: {result.status}")
print(f"Search result: {result.blackboard.get('search_result', 'found')}")
```

### Run with JavaScript SDK

```typescript
const result = await runtime.executeBtree({
  tree: 'search_with_fallback',
  treeYaml: readFileSync('search_with_fallback.yaml', 'utf-8'),
  maxTicks: 500,
  timeoutSecs: 120,
  blackboard: { target_id: 'package_42' },
});

console.log(`Status: ${result.status}`);
console.log(`Search result: ${result.blackboard.search_result ?? 'found'}`);
```

## 3. Navigate to Waypoint

A focused navigation pattern with pre-checks (battery level, localization quality) and post-arrival confirmation.

### YAML Definition

```yaml
name: navigate_to_waypoint
type: sequence
children:
  - name: pre_checks
    type: sequence
    children:
      - name: check_battery
        type: condition
        condition: blackboard_gte
        params:
          key: battery_level
          value: 20

      - name: check_localization
        type: condition
        condition: blackboard_eq
        params:
          key: localization_status
          value: "good"

  - name: navigate
    type: action
    action: navigate
    params:
      x: 7.5
      y: 3.2
      orientation: 1.57
      label: "Loading Dock"

  - name: confirm_arrival
    type: sequence
    children:
      - name: check_position
        type: condition
        condition: position_within
        params:
          target_x: 7.5
          target_y: 3.2
          tolerance: 0.5

      - name: mark_arrived
        type: action
        action: set_blackboard
        params:
          key: arrival_status
          value: "arrived_at_loading_dock"
```

### Run with Python SDK

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

result = runtime.execute_btree(
    tree="navigate_to_waypoint",
    tree_yaml=open("navigate_to_waypoint.yaml").read(),
    max_ticks=300,
    timeout_secs=90,
    blackboard={
        "battery_level": 85,
        "localization_status": "good",
    },
)

print(f"Status: {result.status}")
print(f"Arrival: {result.blackboard.get('arrival_status')}")
```

### Run with JavaScript SDK

```typescript
const result = await runtime.executeBtree({
  tree: 'navigate_to_waypoint',
  treeYaml: readFileSync('navigate_to_waypoint.yaml', 'utf-8'),
  maxTicks: 300,
  timeoutSecs: 90,
  blackboard: {
    battery_level: 85,
    localization_status: 'good',
  },
});

console.log(`Status: ${result.status}`);
console.log(`Arrival: ${result.blackboard.arrival_status}`);
```

## 4. Error Recovery Pattern

A robust pattern that retries the primary action up to 3 times. If all retries fail, an LLM-powered recovery node generates an alternative plan.

### YAML Definition

```yaml
name: error_recovery
type: selector
children:
  - name: primary_with_retry
    type: decorator
    decorator: retry
    max_attempts: 3
    child:
      name: primary_task
      type: sequence
      children:
        - name: navigate_to_target
          type: action
          action: navigate
          params:
            x: 5.0
            y: 5.0
            label: "Target"

        - name: perform_action
          type: action
          action: pick_object
          params:
            object_id: "box_17"

  - name: llm_recovery
    type: sequence
    children:
      - name: set_failure_context
        type: action
        action: set_blackboard
        params:
          key: failure_reason
          value: "Primary task failed after 3 retries"

      - name: ask_llm_for_recovery
        type: llm_node
        prompt_key: failure_reason
        output_key: recovery_plan
        system_prompt: |
          You are a robot recovery planner. Given a failure description,
          output a JSON behavior tree that attempts an alternative approach.
          Consider alternative routes, different grip strategies, or
          requesting human assistance.

      - name: execute_recovery
        type: subtree_loader
        plan_key: recovery_plan

  - name: request_human_help
    type: action
    action: set_blackboard
    params:
      key: status
      value: "requires_human_intervention"
```

### Run with Python SDK

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

result = runtime.execute_btree(
    tree="error_recovery",
    tree_yaml=open("error_recovery.yaml").read(),
    max_ticks=1000,
    timeout_secs=300,
    llm_config={
        "model": "phi3",
        "temperature": 0.3,
        "max_tokens": 1024,
    },
)

print(f"Status: {result.status}")
if result.blackboard.get("status") == "requires_human_intervention":
    print("Robot needs human help.")
elif result.blackboard.get("recovery_plan"):
    print("LLM recovery was used.")
else:
    print("Primary task succeeded.")
```

### Run with JavaScript SDK

```typescript
const result = await runtime.executeBtree({
  tree: 'error_recovery',
  treeYaml: readFileSync('error_recovery.yaml', 'utf-8'),
  maxTicks: 1000,
  timeoutSecs: 300,
  llmConfig: {
    model: 'phi3',
    temperature: 0.3,
    maxTokens: 1024,
  },
});

console.log(`Status: ${result.status}`);
if (result.blackboard.status === 'requires_human_intervention') {
  console.log('Robot needs human help.');
} else if (result.blackboard.recovery_plan) {
  console.log('LLM recovery was used.');
} else {
  console.log('Primary task succeeded.');
}
```

## 5. LLM-Powered Planning

Instead of hand-authoring every branch, give the LLM a high-level goal and let it generate the behavior tree at runtime. The tree below sets a mission goal, asks the LLM to plan, and then executes the generated subtree.

### YAML Definition

```yaml
name: llm_planning_mission
type: sequence
children:
  - name: set_mission_goal
    type: action
    action: set_blackboard
    params:
      key: mission_goal
      value: >
        Survey the warehouse floor. Visit aisles 1 through 4.
        At each aisle, scan for misplaced inventory.
        Report findings to the control system.

  - name: generate_plan
    type: llm_node
    prompt_key: mission_goal
    output_key: generated_plan
    system_prompt: |
      You are a behavior tree planner for a warehouse robot.
      Given a mission description, output a JSON behavior tree.
      Use only these node types: sequence, selector, action, condition.
      Available actions: navigate, scan_area, report, set_blackboard.
      Output valid JSON only.

  - name: execute_generated_plan
    type: subtree_loader
    plan_key: generated_plan

  - name: mark_complete
    type: action
    action: set_blackboard
    params:
      key: mission_status
      value: "survey_complete"
```

### Run with Python SDK

```python
from igris import Runtime

runtime = Runtime(base_url="http://localhost:8080")

result = runtime.execute_btree(
    tree="llm_planning_mission",
    tree_yaml=open("llm_planning_mission.yaml").read(),
    max_ticks=2000,
    timeout_secs=600,
    llm_config={
        "model": "phi3",
        "temperature": 0.2,
        "max_tokens": 2048,
    },
)

print(f"Status: {result.status}")
print(f"Mission: {result.blackboard.get('mission_status')}")

# Inspect the LLM-generated plan
import json
plan = json.loads(result.blackboard.get("generated_plan", "{}"))
print(f"Generated plan nodes: {len(plan.get('children', []))}")
```

### Run with JavaScript SDK

```typescript
const result = await runtime.executeBtree({
  tree: 'llm_planning_mission',
  treeYaml: readFileSync('llm_planning_mission.yaml', 'utf-8'),
  maxTicks: 2000,
  timeoutSecs: 600,
  llmConfig: {
    model: 'phi3',
    temperature: 0.2,
    maxTokens: 2048,
  },
});

console.log(`Status: ${result.status}`);
console.log(`Mission: ${result.blackboard.mission_status}`);

// Inspect the generated plan
const plan = JSON.parse(result.blackboard.generated_plan ?? '{}');
console.log(`Generated plan nodes: ${plan.children?.length ?? 0}`);
```

## Tips

1. **Start with deterministic trees.** Use patterns 1-3 before introducing LLM nodes. Deterministic trees are easier to debug and test.
2. **Set timeouts.** Always pass `timeout_secs` to prevent runaway execution.
3. **Limit LLM output.** Keep `max_tokens` low for plan generation to avoid overly complex trees.
4. **Use the blackboard for state.** Pass initial state via the `blackboard` parameter and read final state from `result.blackboard`.
5. **Combine patterns.** Nest a patrol sequence inside an error recovery selector for production-grade robustness.
